`agentic-memory`, `agentic-tools` and `agentic-capture` fold into the `agentic-helpers` program, which answers to each old name; the hook programs `agentic-shell-guard`, `agentic-grounding-gate` and `agentic-scratch` stay separate.

- **One program, four commands.** `source/hooks/cmd/agentic-helpers` dispatches on the name it runs under (`filepath.Base` of `os.Args[0]`): `agentic-memory`, `agentic-tools` and `agentic-capture` run what their own `main` runs today, and `agentic-helpers` keeps `check` and `bound`. The other three `cmd/` folders for the commands go.
- **The names stay.** Skills, `plugin/hooks/hooks.json`, `.mcp.json`, `plugin/bin`, the docs, hook output prefixes, `pieces.Binary`, and the grounding gate's match on `agentic-capture` keep every name. The release archive carries `agentic-memory`, `agentic-tools` and `agentic-capture` as links to `agentic-helpers`; the launcher (`plugin/hooks/run`) and `go install` into `.claude/bin` produce the same links.
- **Guards stay apart.** Shell-guard and the grounding gate refuse a call when they fail, so they keep programs whose startup loads only their own packages.

Why: each program carries its own copy of the runtime and the shared packages, so a release unpacks to 50 MB (2.25.1) and downloads as 21 to 23 MB. The commands share most of their packages, and folding them saves about 25 MB per release.

Rejected:
- **Folding all seven:** a release about a third of today's size, but a fault in any package's startup code (a Go panic exits 2, which Claude Code reads as a refusal) would refuse every Bash call through shell-guard and every graph call through the gate; and every hook start would pay the setup of every package (shell-guard 0.7 ms today, about 3 ms folded, twice per Bash call).
- **A new program for the three commands:** a new name in the release and the docs, with `check` and `bound` living apart from the other commands.
- **Keeping seven programs:** no change, about 25 MB more per release than needed.

Accepted costs: `agentic-helpers bound`, which shell-guard puts in place of a missing `timeout`, starts with memory's and tools' packages loaded, about 2 ms more per bounded command; build, archive and launcher changes; a startup fault in one command's packages now breaks all four commands.

Acceptance:

1. The release archive holds one `agentic-helpers` program and `agentic-memory`, `agentic-tools`, `agentic-capture` as links to it, beside the three hook programs.
2. Each old name runs its command as before, proven by the functional tests of each command run through the folded program under that name.
3. `GOBIN="$PWD/.claude/bin" go install -C source/hooks ./cmd/...` and the launcher with `AGENTIC_HELPERS_BIN_DIR` set both leave a working `agentic-memory`, `agentic-tools` and `agentic-capture`.
4. An unpacked release takes at most 30 MB.
