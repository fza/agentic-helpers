The cache root's Time Machine exclusion, the daily reclaim of week-old keys, and the daily prune of release folders are built on `main` and proven end to end with binaries built from `d2290e7`, run against throwaway data, cache and plugin homes: commits `249d87e` (exclusion), `33b93b8` (reclaim) and `e53d6b3` (prune). One record covers all three because one build and one live run proved them together.

- **Time Machine exclusion (20261103-000829-d-tac-ppa):** after `agentic-helpers check` ran as the SessionStart hook, the cache root carried `com.apple.metadata:com_apple_backup_excludeItem` and `tmutil isexcluded` answered `[Excluded]`, while the data home stayed `[Included]` with no mark. With the cache root removed, `agentic-memory claim main` recreated it already marked. The decision's check that a failing set changes nothing SessionStart says needs a volume without extended attributes and rests on `TestAFailingBackupMarkChangesNothingSessionStartSays`.
- **Stale key reclaim (20261103-001032-d-tac-h1a):** `agentic-tools start` dropped keys written 192 hours earlier from the prompt vectors, the store's tools session file and the shared seen file, kept 24-hour-old keys, wrote the `.reclaimed` mark, and shrank the store's file from 8,519,680 to 2,228,224 bytes; a second start the same day dropped nothing, and with the mark two days old the next start dropped a new week-old key. `agentic-tools end` still removed its own session's keys at once.
- **Release prune (20261103-004231-d-tac-cjs):** in a fake data directory holding versions 1.0.0 (no mark), 1.1.0 (used 13 days ago), 1.2.0 (used 20 days ago), 1.3.0 (a running `agentic-helpers bound` from it) and 2.0.0 (the version the manifest names), plus `9.9`, `notaversion`, `stray.txt` and a leftover `.pruned-0.9.0`, `agentic-helpers prune` deleted 1.0.0 and 1.2.0 and the leftover, and kept everything else; once the process ended, the next run deleted 1.3.0. `agentic-memory session-start` started the detached daily run once per day. The launcher's `used` mark rests on `internal/plugin/used_test.go`, which runs `plugin/hooks/run` itself against a fake data directory: the shell guard on this machine refuses running the launcher by hand.
