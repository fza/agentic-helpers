On macOS, agentic-helpers keeps its cache root out of Time Machine backups by setting Time Machine's sticky exclusion mark on it.

- **What:** the extended attribute `com.apple.metadata:com_apple_backup_excludeItem` (value `com.apple.backupd`, the mark `tmutil addexclusion` sets without `-p`) on the cache root, `$XDG_CACHE_HOME/agentic-helpers`, else `~/.cache/agentic-helpers` (`home.Roots.Cache`).
- **When:** at SessionStart, set where the root exists without the mark, and when a writer creates the root. Set through `unix.Setxattr` from `golang.org/x/sys`, already a dependency, so no `tmutil` process runs. A failure to set it is ignored: the backup only costs more.
- **Where not:** the data home (`$XDG_DATA_HOME/agentic-helpers`: memory logs, the tool library, attachments) stays in backups, and other platforms get nothing.

Why: everything under the cache root rebuilds itself (slot files, vector segments, prompt vectors, embedder calibration), yet Time Machine backs it up (`tmutil isexcluded` answers `[Included]`). A backup copies a changed file whole, so each large slot file is copied again whenever any box in it changes, even under the size-class layout (20261103-000615-d-tac-m0d). The mark is sticky: it travels with the folder and survives a move or restore.

Rejected:
- **A plugin option to opt out:** one more setting to document and test, for a case nobody has.
- **`tmutil addexclusion` as a subprocess:** a process per check where one system call does the same.
- **A path exclusion (`tmutil addexclusion -p`):** needs root, and breaks when the folder moves.
- **Leaving it in backups:** every backup copies the whole slot files on machines running Time Machine.

Accepted cost: a user who wants the cache backed up must remove the mark by hand, and SessionStart sets it again.

Acceptance:

1. On macOS, after SessionStart, `tmutil isexcluded` on the cache root answers `[Excluded]`.
2. A cache root created by a writer carries the mark, shown by a test reading the attribute back.
3. The data home carries no mark.
4. A failing set (a file system without extended attributes) leaves the hook's output and exit unchanged.
