`agentic-scratch` folds into the `agentic-helpers` program as a fourth name, the way `agentic-memory`, `agentic-tools` and `agentic-capture` did, so an unpacked release meets the 30 MB criterion of the fold decision (20261103-004053-d-tac-krg) on amd64 too.

- **One more name.** `source/hooks/cmd/agentic-helpers` gains `agentic-scratch` in its `commands` table and a link in its `links/`; `cmd/agentic-scratch` goes. The release archive carries `agentic-scratch` as a link, and the launcher with `AGENTIC_HELPERS_BIN_DIR` set links it like the other three names.
- **The name stays.** `plugin/hooks/hooks.json`, the skill, the docs and the scratch hook's output keep `agentic-scratch`.
- **Guards stay apart.** `agentic-shell-guard` and `agentic-grounding-gate` remain programs of their own: they refuse a call when they fail.

Why: with the three commands folded, an unpacked release is 29.2 to 29.8 MiB on arm64 but 31.8 MiB (linux) and 32.4 MiB (darwin) on amd64, over the 30 MB the fold decision sets. `agentic-scratch` carries its own runtime and shared packages, and it is the one remaining program whose failure refuses nothing: it runs only at SessionStart (`start`) and SessionEnd (`end`), so the reason the guards stay apart does not hold for it.

Rejected:
- **A per-architecture budget** (30 MB on arm64, 33 MB on amd64): no build work, but a looser criterion with 0.6 MB of headroom on amd64.
- **Holding 30 MB by cutting code elsewhere** (dependencies, package-level regexes, tables): effort of unknown size with no guaranteed result, blocking the fold's done.

Accepted costs: `agentic-scratch` starts with the shared packages loaded, about 0.8 ms more at each SessionStart and SessionEnd; a startup fault in any command's packages now also stops `agentic-scratch start` and `end` for that session, so its scratch folder is neither prepared nor swept.

Acceptance:

1. The release archive holds `agentic-scratch` as a link to `agentic-helpers`, and no `agentic-scratch` program of its own.
2. `agentic-scratch start` and `agentic-scratch end` behave as before, proven by the scratch functional tests run through the folded program under that name.
3. The launcher with `AGENTIC_HELPERS_BIN_DIR` set leaves a working `agentic-scratch` link.
4. An unpacked release takes at most 30 MB on every platform it ships for: darwin and linux, amd64 and arm64.
