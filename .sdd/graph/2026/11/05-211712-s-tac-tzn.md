`agentic-memory` reads another seat's state ledger read-only, and a search given both `--all-seats` and `--seat` narrows to the named seats, built in commits fa585cdc (`feat: show another seat's state ledger read-only`) and 05d1267d (`fix: let named seats narrow a search across every seat`) on branch `v2`, not yet released. It builds on the per-seat line ledger of 20261101-190255-d-tac-6hl, where no seat reached another's.

- `show state --seat <seat>` (MCP `seat`, a string) reads another seat's ledger in the caller's project, with or without a seat held: the same lines, hook lines among them, the same flags and folds, each fold line naming `--seat <seat>` again; `--json` and MCP carry it as `state`. A seat the project lacks is refused with the seats it has. `--seat` takes one seat and needs the id `state`.
- Writes stay the caller's own: `ack` takes no `--seat`, and an address of another seat's line names no line of the caller's.
- `--seat` with `--all-seats` searches the named seats, where `--all-seats` had searched every seat whatever `--seat` named.
