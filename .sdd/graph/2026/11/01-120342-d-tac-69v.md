A landed-commit match stays stored until its todo, item or trap is acted on: ticked, retired or superseded, or the agent dismisses the match with a new command `agentic-memory landed dismiss <id>` (MCP: the same through the memory server). It is shown once per context, like every entry already is: after a compaction, `/clear`, a resume or a new claim, the brief shows its flag again. This replaces forgetting a match the moment its line is delivered, from 20261101-110914-d-tac-pu1, which 20261101-120217-s-tac-r56 found loses a hint delivered just before a compaction: the post-compaction brief no longer flags the todo, so it reads as open again.

**Once per context.** The running-session line names a match once in a context; the brief flag `retire? landed:` (an item's `ack #<item>? landed:`) prints on the entry's line in every brief, including a seen pointer's. A match the agent leaves alone costs one brief line per context until handled.

**Dismiss.** `agentic-memory landed dismiss <id>` (an entry id or `<todo>#<item>`) forgets that entry's or item's stored match without ending the entry, for a match the agent checked and found not to settle the work; it takes several ids, all or nothing, like the other change commands. A later commit may match the entry again.

**Why.** A hint the agent never acted on is as much owed after a compaction as before; forgetting it on delivery made the feature fail at the moment it is needed.

**Rejected.** Keeping a match for one brief after delivery: a second compaction close behind the first still loses it, and it shows twice even when acted on at once. Keeping the build: a hint delivered before compaction is lost.

**Accepted costs.** An ignored match returns in each context until dismissed or settled; a new subcommand and MCP tool within the server's description budget.

**Acceptance.**
- A delivered match survives a compaction and a new claim; the brief after either still flags the entry.
- The running-session line names a match once per context.
- Ticking, retiring or superseding the entry, or `landed dismiss`, removes its match; dismissing an id with no match refuses it, all or nothing.
- Skill, `docs/memory/usage.md` and the MCP description name `landed dismiss`.
