Nothing agentic-memory says to the agent reaches the user's screen: every line goes out as `additionalContext` on a hook event Claude Code hands the agent without showing it, and Stop sends nothing.

- **Stop holds nothing.** The overdue backstop (`stop()`, `backstopText`) and the do-now hold (`holdForDoNow`) stop calling `hold`. Stop marks the owed line in the `ladder/<session>` key of `sessions.slots`, where the nudge ladder keeps its count, and prints nothing.
- **The owed line goes out at the next hook event with a hidden channel**: PreToolUse, PostToolUse, UserPromptSubmit or SessionStart, whichever fires first.
- **Plain stdout goes away.** `say` (`internal/memory/memory.go`) writes `additionalContext` JSON on UserPromptSubmit, SessionStart and the session-log pieces, since Claude Code shows a hook's plain stdout in the transcript.

Why: a Stop hook's `additionalContext` always renders as "Stop hook feedback" (20261101-105300-s-tac-n5b), and memory upkeep is meant to happen in the background, unseen by the user. The scarcity rule for hidden messages (20261027-222117-d-tac-yjy) still binds what is sent; this decides only where it goes.

Left open: how often an owed line repeats before the agent answers it, and what counts as proof that the agent did the upkeep rather than made any memory call.

Acceptance:

1. No memory hook prints to a channel Claude Code shows the user: no Stop `additionalContext`, no plain stdout on any event.
2. An overdue or do-now line owed at Stop reaches the agent at the next PreToolUse, PostToolUse, UserPromptSubmit or SessionStart, as `additionalContext`.
3. The agent-memory skill and `docs/memory/` quote the new wording and say where it arrives.

Accepted cost: an agent that ends its turn without complying is no longer held at Stop. The line waits for the next prompt or tool call; a seat whose agent stops for good leaves it to the replay the next SessionStart after a compaction prints, which asks for state lines again.

Rejected: keeping the Stop hold for the last few percent before compaction (the user still sees it, for exactly the agents that do not comply); dropping the backstop altogether (an agent ignoring hidden lines is never pushed again).
