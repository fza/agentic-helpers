The `sdd` output collapse is built in agentic-helpers commits 76ef7d4, 4e91860 and 174ea86 on `main`, not yet released, closing 20261101-151135-d-tac-uom: `agentic-grounding-gate collapse`, on `PostToolUse` for every `mcp__sdd__` tool, shortens an answer carrying sdd's structured fields to what the calling agent was not shown, and `agentic-grounding-gate spawn`, on `PreToolUse` for `Agent` and `Task`, keeps a fork its spawner's set. The logic lives in `internal/collapse`; sets sit in `.sdd/tmp/grounding-gate/` per main thread and per subagent, emptied at a compaction, `/clear` and resume and removed at session end. `agentic-helpers check` prints one SessionStart line while `sdd config get sessions.token_saving` answers `on` in a project the gate works on. sdd v0.18.0-alpha.2.fza.41 is the minimum version, named in README and `docs/grounding-gate/usage.md`.

**Deviations.** sdd answers a show's chains as flat preorder lists carrying `depth`, since its MCP SDK builds no output schema for a recursive type, so a collapsed chain item keeps its depth instead of a nested chain. Collapsing follows only the machine switch `grounding_gate_enabled`: a project's `enabled: false` lifts the gate and keeps collapsing, which gates nothing. The structure check also looks into `base_junction` and `open_instances`, since `abandon` and a `next` ending a move answer only the junction's serve there, a gap the live probe found.

**Proof.** Unit tests cover asked ids printing in full, chain and hit pointers, a changed line printing in full, no collapse against the answer itself, serves, resume, the text form passing whole and every answer form; functional tests through the gate's `Main` cover per-agent sets, a fork starting from its spawner's set as kept at the spawn, a fresh subagent's empty set, the reset sources, session end, failed calls and the switches. Every guard was broken and its test turned red, except the structure check on the plain object form, which text answers pass anyway for lack of the fields. A headless `claude -p` against sdd's fork build with an isolated config holding `sessions.token_saving: off` showed a repeated show shrink from 9426 to 7714 characters with the asked entry whole, both searches collapse every hit already shown, and repeated serves and `abandon` collapse their lanes, framing blocks and schema. Not proven live: a fork's inherited set, covered by functional tests and by the spawn call id Claude Code writes into a fork's `agent-<id>.meta.json`, the same link agentic-memory's per-subagent shown sets rest on.
