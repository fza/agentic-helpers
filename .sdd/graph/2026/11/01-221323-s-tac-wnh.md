Persisted agentic-helpers data now migrates through the shared runner `internal/formatsteps`, built in commits 9882ebe, 78497db, b00341d and a722df2, released in v2.25.0, which closes the shared migration runner decision 20261101-193020-d-tac-lh5.

Criterion 1: the runner refuses a format newer than its table and writes `format.json` after each step, covered by `TestRunStepsFromTheFormatFound` and `TestRunRefusesANewerFormat`. Criterion 2: the memory store's steps live in one table ending at format 8; `TestANewerStoreIsRefused` and `TestASetAsideLogNeverBlocksTheNextRun` cover the two defects, fixed in 78497db. Criterion 3: the tools library and slot-file adoption each hold a step table. Criterion 4: `scripts/release-fixture` writes a release's tree and `dump.json`, the v2.24.0 and v2.25.0 fixtures are committed (0a6d1ba for the second), and `TestEveryCommittedReleaseMigratesToWhatItHeld` and `TestTheNamedReleaseHasAFixture` pass on both. Criterion 5: `TestEveryStepCarriesOnFromAnyOperation`, `TestEveryLibraryOperationCarriesOn` and `TestAdoptionCarriesOnFromAnyOperation` cut every step after every operation, one test per component rather than the single test the criterion names. Criterion 6: the docs describe the runner, the fixtures and the release step.

Live, the memory stores of the agentic-helpers and fdbox projects read format 8, and the agentic-helpers store holds no set-aside log.

Deviations. The home layout is a component with an empty table: format 1 is the only format the home has held, so `Roots.Layout` has no step to run, and the move of earlier releases into the home stays with `internal/migration`, a move between folders rather than a step within one. The fixture script writes seat state through `ack state --add` since 3eb45ad, the only form v2.25.0 and later take, so it can no longer regenerate a fixture of a release before v2.25.0. The v2.25.0 fixture came after that release, whose named-release test therefore failed on `main` from the release commit until 0a6d1ba. Criterion 6 also asks that each new guard be broken once and its test watched failing: no record of those runs survives, so that part stays unattested.
