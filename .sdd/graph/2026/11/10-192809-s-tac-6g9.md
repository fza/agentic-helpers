Memory reads a `graph_repo` checkout's graph from sdd's own copy, found once through `sdd repo path` and kept in `graph-clone.json`, built in commit `8337bfe`; no release carries it yet.

`graphconfig.GraphRepo` reads `graph_repo` from the checkout's own `.sdd/`; memory's graph resolution asks `sdd repo path` for it where the capability probe finds `repo` listing `path` in `sdd repo --help`, keeps the answer while `graph_repo` is unchanged and its folder exists, and reads entries, `repo_id` and `language` through the copy's own `.sdd/`. The probe's `surfaces` went from 3 to 4. `projectkey.RepoID` takes the `graph_repo` value before any declared `repo_id`. `docs/memory/architecture.md`, `docs/memory/usage.md` and `docs/plugin/usage.md` describe the layout.

Each acceptance criterion has its test, with `sdd` faked:
- an entry written into the copy reaches the capture notice, and the claim's language is the copy's, not the `project_dir` checkout's (`source/hooks/internal/memory/graphrepo_test.go`);
- with `graph-clone.json` in place, later processes run neither `sdd repo path` nor the probe;
- a changed `graph_repo`, and a removed folder, each ask once more;
- with stock sdd's help, which lists no `path` under `repo`, memory reads the `project_dir` checkout and runs no `sdd repo path`; a failing answer and one naming no folder fall back the same way and keep nothing;
- a `graph_repo` checkout's key is the `graph_repo` value (`source/hooks/internal/projectkey/projectkey_test.go`).
The probe's tests cover the new surface, a build listing no `repo` command, which is never asked for its help, and an answer cached under the old `surfaces`, which is probed again.

Two checks had no failing test when broken and were removed: a failed `sdd repo path` and a failed `sdd repo --help` each answer with empty text, which the folder check and the help parse already reject. No test reads a `graph_repo` checkout lacking both a copy and a `project_dir`; there memory reads the GRAPH-ELSEWHERE guard file as its entries folder and finds none, as the directive's "else reads no graph" states.
