Shell-guard now judges the code a shell runs past its options and the script behind a lone `-`, so `bash -c -- 'rm -rf ~/x'`, which passed silently, is denied, and `zsh - x.sh` is read. In agentic-helpers commit bd0656a on `main`, pushed, not released. It takes up the lone `-` that 20261102-122759-s-tac-zx9 left open.

The code word was the larger defect. `shellCode` took the word right after `-c`, while every shell goes on reading options and runs its first operand past them: `bash -c -e 'code'`, `-c -- 'code'`, `-c - 'code'`, `-c -s 'code'`, `-c -o pipefail 'code'`, `-co pipefail 'code'`. The guard judged the option word as the code and the real code as nothing, so any removal behind it was allowed with no reason given. Marker code run through bash, sh, zsh, dash and ksh confirms that form on each, and the installed guard denies it after the fix.

One walk, `firstOperand` in `internal/shellwalk/scripts.go`, now serves the script, the piped-input check and the code. `namesScript` is removed: it restated the walk and differed only in refusing every `--`, so `echo x | bash -- x.sh` is now allowed with the script judged, as `echo x | bash x.sh` already was. `--` and a lone `-` end the options, a word past them spelling `-c` is an operand, and `-` alone leaves the input as the code. `-C` is a value option on fish only: `bash -C x.sh` went unread as a value, and it now reads as the flag those shells' manuals give it.

fish stays as it was. Its `-c`, `-C`, `--command` and `--init-command` take the next word whatever it spells, and its manual gives `-` no role, so `-` stays the input to fish. fish is not installed here, so this is unmeasured.

Proof: 30 cases failed before the fix and pass after it, every guard of the walk was broken and caught with the sources restored byte-identically, and `go vet` and `go test -race` pass. The `shell - script` form itself was not run: it stands on bash's and zsh's manuals and POSIX for sh, plus the measured `-c - code` form showing `-` ends options on all five shells. `-C` as a flag stands on the bash, zsh and dash manuals, not on a run. dash, ksh and mksh are treated like bash.

Accepted cost: `bash --rcfile - -c 'code'` stops the code search at the value `-`, so it asks about an unreadable script instead of denying the code.

Left open: `fish -C 'code' x.fish` runs `x.fish` unread, since any code word ends script reading, and fish's short value options `-d`, `-p` and `-f` take no value in the walk. Both predate this change.
