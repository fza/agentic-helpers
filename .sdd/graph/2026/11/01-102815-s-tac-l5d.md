The three-way placement question for standing instructions is shipped in agentic-helpers v2.22.0 and proven live: a Claude Code session running the released plugin, seated on `main` and given the standing instruction "push without asking", asked one question before writing anything, offering a memory rule on the seat, `CLAUDE.local.md` and `CLAUDE.md` / `AGENTS.md`, each with its reach and cost and one marked recommended. The answer picked the memory rule, and only then was the rule filed, verbatim and from the user.

Acceptance against the directive:
- The agent-memory skill (`plugin/skills/agent-memory/SKILL.md`, as released in v2.22.0) tells an agent to ask the three-way question for every new standing instruction and write nothing before the answer; the live run followed it.
- The same skill states that `CLAUDE.local.md` and `CLAUDE.md` win over a contradicting rule, which the agent supersedes with one line to the user. The live run raised no contradiction to exercise it: the new rule and the checkout's `CLAUDE.local.md` grant the same thing.
- `docs/memory/usage.md` describes the question and the file-wins precedence; this repository's `AGENTS.md` memory section defers to the skill and that page.

Noticed in the doing: the instruction was already held by this checkout's `CLAUDE.local.md`. The question said so and recommended that file, since choosing it writes nothing new; the memory rule was still offered and taken, so the same grant now lives in two places that agree.
