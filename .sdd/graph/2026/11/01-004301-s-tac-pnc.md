agentic-memory folds similar-entry hints in a filing reply, names each live seat holder's session in `who`, and keeps a clock mark against a system clock set back, in agentic-helpers commits 299e00d, 6d8b626 and 45b89d7 on `main`, not yet released. It closes the hint-folding directive (20261031-235744-d-tac-73r), the `who` directive (20261031-235809-d-tac-lrj) and the clock directive (20261031-235655-d-tac-o74).

**Proof.** The installed `agentic-memory who`, run read-only on the real store in this checkout, printed the live holder's row with `message: agentic-helpers-70`, the name Claude Code's session listing gives that session, and folded other projects' seats into `+28 seats in other projects: agentic-memory who --all  (run before concluding a seat is not held)`. The folded similar hints and the clock mark are proven by tests only: a real filing would write to the store, and a rollback would move the machine's clock. Tests cover every acceptance criterion over CLI and MCP, with session records and clocks faked under `t.TempDir()`; every new guard was broken, caught by its own test and restored byte-identically. `docs/memory/usage.md`, `docs/memory/architecture.md` and the agent-memory skill describe all three.

**Deviations.**
- The `similar:` line carries no supersede or link command, as an existing test forbids one there; the advice stays in the skill. The former cap of three matches is gone, so the fold count covers every match above the threshold.
- `who` reads the session record under `CLAUDE_CONFIG_DIR` where set, else `~/.claude`; the MCP `who` key is `all`.
- The mark lives in `<store>/clock.json`, with no store format change, since older releases ignore the file. Where the clock equals the mark exactly, memory uses the clock as-is rather than one nanosecond past it: the literal rule shifted every age by a nanosecond under a held clock and broke an existing due-time test; ordering after a rollback is unaffected. Two places stay on the system clock: a waiter token that stores no time, and scratch folder ages read from file modification times, which `docs/memory/architecture.md` names. Two processes raising the mark at the same moment can leave it a few microseconds low.
