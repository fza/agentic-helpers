`mcp__sdd__view` answers collapse in a live Claude Code session: commit 985922e, released in agentic-helpers v2.25.0, reads the `view_sections` sdd v0.18.0-alpha.2.fza.42 answers and shortens each listed entry the calling agent was already shown to its id, title and `shown_earlier`, keeping section name, match count and scores. It runs behind the gate recorded in 20261101-201929-s-tac-wl4.

**Proof.** A Claude Code run on `main` at 8951312, with `sessions.token_saving` off in sdd's global config, found `.sdd/tmp/grounding-gate/<session>.collapse-on.json` written at its start. The view layout `top(4)`, the four hottest entries, read twice through `mcp__sdd__view`, printed every entry in full on the first call, 3319 characters, and on the second call each of the four entries as a pointer, 1115 characters. The run's hooks came from `.claude/bin`, built from a tree whose `internal/collapse` and `internal/grounding` match v2.25.0.

**Deviation.** A collapsed answer reaches the agent as one text block holding the JSON, not as the structured object an untouched answer arrives as; the fields are the same, the string escaping adds a little to the size.

**Not proven live.** A `bodies` view printing in full and a changed entry printing in full rest on the tests in `internal/collapse/view_test.go`.
