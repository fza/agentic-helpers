Every `SKILL.md` and every memory and tools MCP tool and key description has a size budget a test enforces, and the agent-shell-guard skill is split into a core plus reference files, in agentic-helpers commits d370122 and 160217e on `main`, not yet released. Both decisions are guidelines that keep applying (20261031-235720-d-tac-kh4, 20261031-235841-d-tac-b1x), so this done builds what they set without closing them.

**Skills.** Budgets sit about 5% above each skill's size, in `skillBudgets` in `source/hooks/internal/plugin/skillbudget_test.go`, each with its reason. The test also fails on a skill with no budget, on a budget naming no skill, and on a reference file its `SKILL.md` does not link. agent-shell-guard's `SKILL.md` went from 16,869 to 12,394 characters; `scripts.md`, `output.md` and `reference.md` beside it carry the script walkthrough, the per-tool output table and the rare paths. Every backtick span of the old skill is in one of the four files, and `TestTheSkillQuotesEveryRefusal` now requires every refusal reason in the core.

**Descriptions.** Budgets sit about 10% above each description, per tool and with one shared figure per server for keys, plus its own for the `agent` key that repeats on every memory tool, in `source/hooks/internal/memory/descriptionbudget_test.go` and `source/hooks/internal/tools/descriptionbudget_test.go`. No description was shortened.

Padding a copy past its budget under `t.TempDir()` turns each test red; every guard was broken, caught and restored byte-identically. `docs/plugin/architecture.md`, `docs/memory/architecture.md` and `docs/tools/architecture.md` name the budgets and where they live.
