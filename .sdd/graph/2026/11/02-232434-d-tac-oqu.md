While memory upkeep is owed and unanswered, a one-line hidden reminder goes out at every user prompt and at every 10th tool call, as `additionalContext` (20261102-225941-d-tac-em1), until the reminder is answered. Upkeep is owed once the context crosses a nudge threshold of the ladder (measured against Claude Code's compaction window) with no own write since; a reminder is answered as 20261102-232355-d-tac-9pq sets out. This replaces the cap of two reminders per context threshold (`nudgesBeforeBackstop` in `internal/memory/hooks.go`) and the single owed line after it.

Why: an agent that ignores two reminders and one owed line is never reminded again before compaction, and upkeep left undone costs the next context its picture of the work. A line at every prompt and every 10th call keeps an agent from drifting far without a line on every call.

This is an exception to the once-per-cause rule for hidden messages (20261027-222117-d-tac-yjy), for owed memory upkeep alone: every other hidden message keeps firing once per cause.

Accepted cost: about 60 tokens per reminder until the agent answers it.

Rejected: a reminder at every hook point (about 60 tokens on every tool call, and a line seen constantly is learned to be skipped, the reason the scarcity rule exists); keeping two reminders and one owed line (an agent ignoring three lines is never reminded again before compaction).

Acceptance:

1. While upkeep is owed and unanswered, every UserPromptSubmit and every 10th tool call (PreToolUse or PostToolUse, counted per session) carries one reminder line, never more than one per hook event.
2. An answered reminder stops the repeats at once.
3. No reminder reaches a channel Claude Code shows the user.
4. The agent-memory skill quotes the reminder's wording.
