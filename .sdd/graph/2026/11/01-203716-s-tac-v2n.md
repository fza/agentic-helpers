The seat state ledger is built in agentic-helpers commits 6e285ae and 218faea on `main`, not yet released, closing 20261101-190255-d-tac-6hl: `ack state` adds, ticks, removes, undoes and pins a seat's state lines, lines end when what they cite ends or a declared `--until` is reached, hooks add `landed`, `captured`, `dirty` and `asked` lines in place of the hook-written draft and the shipped-work request, and a store of format 7 moves to format 8 with an agent-written slot waiting as `state#old`.

**Deviations.** Ledger rows are `item` rows of the entry `state`, routed by a `stateAddress` pattern in `ack` rather than a widened `itemAddress`. Derived ends are not stored; the slot `ledger-ended/<seat>` tracks which ended lines were shown. `--undo` keeps a line open until ticked or removed; `--decline` and `--order` are refused on state lines. The `asked` line is cut to `entry_target_words`, and hook lines' ends are not listed under `ended since last brief`. The MCP `ack` description budget rose to 200 characters for the `state` ids and the `until` key. A live check found the `asked` line taking a subagent's hand-back as the last prompt; 218faea adds hand-backs and other sessions' messages to the turns Claude Code sends itself, its test red against the unfixed code first.

**Proof.** Tests per acceptance criterion in `internal/memory/ledger_test.go` and `kinds_test.go`, including a real format-7 store fixture as v2.24.0 writes it; every new guard was broken and its test turned red, except the `landedFor` exclusion, caught only by a panic, and a dedupe in `capturedLines`, removed as unreachable. The full suite passes. Live on this checkout's `go install` build: the main seat's free-text slot showed as `state#old` with the request to split it into lines, `ack state --add`, `--remove` and `state#old --done` changed the ledger, hook `landed` lines listed the commits since the claim, and `show state` printed the whole ledger.

**Owed.** Criterion 8: re-measure agent output into state about three days after release. Hook lines are never compacted in the log. A `config.yaml` still naming `state_stale_after_writes` now gets a no-such-option problem at `agentic-helpers check`.
