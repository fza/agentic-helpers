agentic-helpers' layout migration left data behind that nothing reads again: failure markers piling up in the cache, and the pre-home memory folder on macOS.

**Failure markers piled up.** The layout migration (`internal/migration`) opened its lock on every hook call, even in a home already settled. A call that cannot open the lock, such as a sandboxed one, failed and wrote an empty marker under `~/.cache/agentic-helpers/migration-failed/` on every run. Markers never expired and held no cause, while a hook's stderr reaches no transcript, so nothing said why they were there.

**The old memory folder stayed.** The sweep removing the pre-home `~/.claude/agentic-memory` counted a folder holding only Finder's `.DS_Store` as not empty, so on macOS the folder outlived its migration indefinitely.

Cost: a cache folder nobody can explain, and a leftover folder in `~/.claude`. The shared runner's release fixtures and tests (20261101-221323-s-tac-wnh) cover format steps, not what a settled home or a Finder-touched folder leaves behind.
