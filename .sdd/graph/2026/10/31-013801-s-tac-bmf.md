The per-outage recall failure line shipped in commit f6d4a0c on `main`, not yet released: a recall the embedder fails prints `agentic-memory: prompt recall failed, retried each prompt: <error>` once, and the next working recall re-arms it. `docs/memory/architecture.md` names the line in the prompt hook's row.

**Proof.** `go vet ./...` and `go test -race ./...` pass. `TestRecallTellsOfEachEmbedderOutageOnce` covers a first failure, a repeat failure staying silent, and a failure after a working recall printing again; breaking the once-per-outage check and the re-arm each turned its own assertion red, and the file was restored byte-identically. End to end, the installed `go install` build drove the prompt hook in an isolated home with twenty entries and the endpoint switched in its settings: the dead endpoint printed the line on the first prompt and nothing on the second, the live endpoint at `127.0.0.1:1235` recalled silently, and the dead endpoint printed the line again.

**Deviation.** Acceptance item 3 (a working recall with the flag clear writes nothing) is dropped: other writes on every prompt change the same slot file, so no test can tell that write apart, and the repository removes a guard no test can fail. A working recall now writes the shown slot once per prompt.
