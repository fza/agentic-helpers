An agentic-memory seat can be marked private, which hides it from every other project's `who --all` while its own project still lists it. A seat is marked by `agentic-memory claim <seat> --private` (MCP `claim` key `private: true`) or by `agentic-memory private on|off`, which acts on the seat this session holds.

- **CLI-only toggle.** `private` is registered `cliOnly`, like the seldom-run commands of 20261029-022449-d-tac-ygu. An MCP call naming it is refused: `agentic-memory: private is no MCP tool; run it through Bash: agentic-memory private on|off`.
- **Stored on the seat.** The mark stays across sessions until turned off, surviving release and a later claim.
- **Hidden elsewhere.** Another project's `who --all` (text, `--json`, and MCP `who` with `all`), the machine-wide listing of 20261025-232221-d-tac-jg4, shows no trace of a private seat.
- **Shown at home.** Its own project's `who` lists it as usual, the line ending `private`.
- **Entries unchanged.** `--for` and `follow` work inside one project's store, so entries need no change.

Why: `who --all` reads every project's store on the machine and prints each seat with its holder session, pid and claim time (`source/hooks/internal/memory/who.go`).

Rejected: a `+<n> private seats` count elsewhere (reveals that a private seat exists and when it is busy); a whole-project setting (not per session); `private` as an MCP tool (one more schema in every session for a rare command, and it breaks the CLI-only rule).

Accepted costs: a launcher (a tool that claims a seat for a session it starts, through `claim --session`) passes `--private` itself where its seats should stay private, since nothing marks them by default; nobody elsewhere can tell a private seat exists; toggling mid-session takes a Bash call.

Acceptance: `claim --private` hides the seat from another project's `who --all` and `--json`; its own project shows it with `private`; `private off` shows it again; the mark survives release and a later claim; MCP `private` is refused with the CLI line; MCP `claim` with `private: true` marks it. The `agentic-helpers:agent-memory` skill (seat section, CLI-only list, `reference.md`) and `docs/memory/` change with it.
