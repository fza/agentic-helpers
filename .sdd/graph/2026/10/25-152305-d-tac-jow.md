title: Unicode file name anchors
summary: Agentic-memory widens its file-name token to Unicode letters, digits and combining marks, so non-ASCII file names like `docs/Übersicht.md` anchor entries as ASCII ones do. It builds on the entry-language directive (20261025-151706-d-tac-f7p) and the filed-entry anchoring (20261025-014326-d-tac-mvn). A token still anchors only where a matching file exists, so the wider class cannot create false anchors.

agentic-memory recognises a file name in an entry's title or body when it holds letters, digits or combining marks of any script, beside the punctuation already allowed. `pathToken` in `internal/memory/anchors.go` becomes `[\p{L}\p{N}\p{M}_./~-]*[./][\p{L}\p{N}\p{M}_./~-]+`, with the optional line suffix unchanged, so `docs/Übersicht.md` and `src/納品書.go` anchor an entry as `docs/overview.md` does.

Why: an entry anchored to a file shows `drifted` or `gone` once that file changes, which is how a stale entry gets noticed. The ASCII class leaves every entry naming a German, Japanese or other non-ASCII file name without that check, unless the agent remembers `--about` every time. A token anchors only where a regular file exists under it, so the wider class cannot create a false anchor.

Rejected: keeping the ASCII class and relying on `--about` (drift goes unnoticed for every entry where the flag is forgotten, and nothing tells the agent it was needed).

Accepted costs: more tokens per entry reach a `stat` call, such as dotted abbreviations (`z.B.`, `e.g.`), each dropped when no file matches; a name written in one Unicode normalization form does not find a file stored in another on a filesystem that compares bytes, such as ext4. Paths holding spaces still anchor only through `--about`.

Acceptance criteria:

1. A unit test files an entry whose body names `docs/Übersicht.md` and `src/納品書.go`, both existing in a `t.TempDir()` tree, and finds both anchored.
2. The same test names `z.B.` and a non-existent `docs/Fehlt.md`, and finds neither anchored.
3. A line suffix on a non-ASCII path (`src/Größe.go:12`) anchors `src/Größe.go`.
