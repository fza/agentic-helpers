The `agentic-helpers:agent-memory` skill's store-question section and the details of due times move out of `SKILL.md` into files read on demand, and every later feature puts its rare-path text there too, so the core stops regrowing.

**Why.** `SKILL.md` grew from 11.6k characters at the split (20261029-021831-d-tac-93f) to 19k as features landed: todolists, the agent-neutral home and its store question, bind scoping, the migration, due times, tool links. In 36 hours the skill loaded 27 times at about 22.6k characters each, and stays in context for the rest of the session. The store-question section alone is 2.6k characters, read only when a store question, a two-store notice, a bind or merge refusal, or a migration failure appears, which a session rarely meets.

**Changes.**
- A new file `store.md` beside `SKILL.md` takes the store-question section whole. `SKILL.md` keeps two lines: one store per project, a hook asks only where two checkouts compete; never edit `agentic-store` in `.git/` or a store's `identity.json`. The "Read when" table routes `no store is bound to the checkout`, `keep their memory in two stores`, `from the store`, `is not offered for this checkout`, `is this checkout's own store`, `migrating to` and `writers.json cannot be read` to it.
- Due times keep one line in `SKILL.md` (`--due <time>` on a todo or note keeps it out of the brief until it nears; act on a due notice); the brief lines, the mid-run notice, `due <id>` and the past-due flag move to `reference.md`, routed by `due (`, `due later`, `due for` and `--due`.
- Rule for the skill's authors: text an agent needs only when a rare reply or situation appears goes into a file beside the core with a "Read when" row; the core keeps what nearly every session uses and every rule an agent must obey unprompted.

**Risk, judged low.** Each moved passage answers a reply line that names its own next step, and the "Read when" table routes that line to the file. The one rule an agent must keep without being prompted, never editing the pointer or identity files, stays in the core.

**Rejected.** Moving the todolist rules: `ack` runs often and an agent files todolists unprompted. Cutting the core back to 11k: that would move rules agents use every session, which the token-cost criteria (20261029-021515-d-tac-00q) rank below risk.

**Accepted costs.** A store question costs one more `Read`. `SKILL.md` stays near 16k, above the split's 11k target.

**Acceptance.** `SKILL.md` holds neither the store-question walkthrough nor the due-time details; `store.md` and `reference.md` hold them, each quoted reply string still quoted somewhere in the skill's files; the "Read when" table routes every line named above; the plugin's tests pass.
