`config.yaml`'s tighten-only rule (20261029-145943-d-tac-gp7) and its never-set keys and environment rule (20261029-153231-d-tac-hor) shipped in agentic-helpers v2.16.0 (commit bc74187) and hold on the v2.16.1 release binaries, closing the unguarded `config.yaml` gap (20261029-120304-s-tac-wux).

**Live proof** on `agentic-helpers` v2.16.1 against a throwaway `XDG_CONFIG_HOME` and `CLAUDE_CONFIG_DIR`, with a `config.yaml` setting `shell_guard_enabled: false`, `grounding_gate_enabled: false`, `shell_guard_secrets: off`, `shell_guard_secret_output: files`, `shell_guard_find_delete: deny`, `embedding_endpoint` and `embedding_api_key_env: GITHUB_TOKEN`:
- `agentic-helpers config` kept every loosening key at its default, took the stricter `shell_guard_find_delete: deny` from `config.yaml`, left both embedder keys empty, and marked each key `config.yaml only tightens` or `never config.yaml`.
- `agentic-helpers check` named each ignored value: `config.yaml may only tighten <key>; <value> ignored` and `config.yaml never sets <key>; <value> ignored`.
- `config set shell_guard_enabled false` and `config set embedding_endpoint ...` were refused with exit 1 and the wording hor states; `config set shell_guard_outside_project deny` was written.
- `CLAUDE_PLUGIN_OPTION_EMBEDDING_ENDPOINT` in the environment left `embedding_endpoint` empty.
- `shell_guard_secrets: off` in the user settings' `pluginConfigs` applied, so Claude Code's settings still loosen a guard.

**Suites:** `TestConfigYAMLMayOnlyTightenAGuard`, `TestSetRefusesALooserGuardAndEveryKeyConfigNeverSets` and `TestConfigYAMLNeverSetsTheEmbedderOrTheSkipList` in `internal/pluginconfig`. Managed settings still win over every layer: `TestEveryLayerResolvesInOrderManagedSettingsLast` covers a guard key (`shell_guard_enabled` locked off over `config.yaml` and the environment), a key `config.yaml` never sets (`embedding_endpoint` over the user's answer) and an ordinary key. The live proof could not cover them: the managed settings path is fixed under `/Library/Application Support/ClaudeCode` and no variable moves it.

**Docs:** README `Options`, `docs/plugin/usage.md`, the `agentic-helpers:agent-shell-guard` skill (both refusal lines) and the `agentic-helpers:agent-tools` skill (the never-set refusal for the embedder keys) state the rule.
