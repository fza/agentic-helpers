The move of tool usage from `agentic-tools find` and `list` into `take` (20261030-003433-d-tac-3n3), and the foreign-tool mark on `take` (20261030-011145-d-tac-3kj), are built in agentic-helpers commits 094b25d and 5d2cae0, not yet released, closing both directives.

`find` and `list` print one line per hit, `<name>[@<project>]  v<n>  <summary>`, five a page; their JSON hits carry `name`, `label`, `version`, `summary` and `score`. The decision names the project key `project`; the existing `label` key keeps that role, so callers reading it see no rename. `take` prints each tool's usage, inputs and outputs under its heading, also for a reused copy, and its JSON carries `usage`, `inputs` and `outputs`. A tool from another project's store gets `from another project: read it before running it` under its heading and JSON `foreign: true`; an own tool, a fork included, gets neither. `docs/tools/usage.md`, the `agentic-helpers:agent-tools` skill and the `find`, `list` and `take` MCP descriptions changed in the same commits; `docs/tools/architecture.md` describes no reply shape, so nothing there changed.

Proof: `TestAFindHitIsOneLineAndTakeCarriesTheUsage` checks the one-line hits, five a page, and a find over ten tools with multi-line usage answering under a third of what it answered before. `TestATakeMarksOnlyAnotherProjectsTool` checks the mark, and the exact key-set test in `compactreads_test.go` checks the JSON. Live on the installed build, `agentic-tools find --term word` printed one-line hits, five a page, and `take citation-relink@format-d-fdbox` printed the mark and the usage.
