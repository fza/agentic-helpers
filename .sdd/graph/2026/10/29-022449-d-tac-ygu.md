The plugin's `memory` MCP server (agentic-memory's tools, server `memory` in `plugin/.mcp.json`) shrinks its tool listing in three ways: no tool lists an `outputSchema`, input schemas lose no-effect keys and carry terse key descriptions, and seldom-run commands become CLI-only.

1. **No output schemas.** Every tool still answers one JSON object as 20261027-180531-d-tac-04v set; only the per-tool `outputSchema` leaves `tools/list`. The listing falls from 52.2k to about 16.5k characters (output schemas were 35.7k, `brief`'s alone 16k).
2. **Terse inputs.** The `json` key ("no effect: every answer is JSON") leaves every read's schema. A call that still sends `json` to a command taking it is let through, so no caller breaks; for this server that replaces the v3.0.0 removal-with-refusal of 20261027-180803-d-tac-lko, while the `tools` server keeps its `json` key and output schemas. Every key description added by 20261027-225155-d-tac-0gp is shortened to a terse phrase. Input schemas fall from about 11.8k to about 6k characters.
3. **Fewer tools.** `lifetime`, `drop`, `follow`, `unfollow`, `trust`, `holder`, `rename`, `rekind`, `retain`, `merge`, `unlink`, `revive`, `attach` and `read` are marked `cliOnly` in `source/hooks/internal/memory/commands.go` and run through Bash only; each saw under 15 uses in three days of transcripts. The `agentic-helpers:agent-memory` skill names which commands are CLI-only.

Why: `tools/list` was 52.2k characters for 32 tools. Claude sees only a tool's description and input parameters, loaded per tool when selected (a `ToolSearch` select of `memory__who` returned description and parameters, no output schema), while every session's system prompt lists all tool names up front. Output schemas cost context the model never reads, and each rarely used tool costs every session a listing line.

Rejected: keeping output schemas (Claude never reads them, and they were two thirds of the listing); removing `json` with a refusal for callers still sending it (breaks callers for a key that does nothing).

Accepted costs: another MCP client loses typed result descriptions; terse descriptions explain less, so the skill carries the meaning; an agent needing a CLI-only command goes through Bash. The skill's `reference.md` MCP section and the `docs/memory/` MCP pages change with it.

Acceptance: no memory tool lists `outputSchema`; no memory schema lists `json`, and a call sending `json` answers as one without; every CLI-only command is absent from `tools/list` and still runs from the command line; the skill lists the CLI-only commands.
