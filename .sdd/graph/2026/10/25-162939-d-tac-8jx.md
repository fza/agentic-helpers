`agentic-memory who`, and the `memory` MCP tool `who` (no keys), lists every live seated session on the machine, in every project: it walks every store under `~/.claude/agentic-memory/`, reads each claim in its `seats/` directory, and prints one line per claim whose holder is alive, sorted by project, then seat:

    github.com/fza/agentic-helpers   main   8109b4dc  pid 87518  since 2026-10-25 15:03 CET
    gitlab.com/format-d/devops/fdbox main   794c9630  pid 24808  since 2026-10-25 05:03 CET

- **Columns**: the project key, the seat's current name, the session id's first 8 characters, the pid, and the claim's time in the local zone with its abbreviation, as every printed stamp is.
- **Liveness** is the check of 20261025-162618-d-tac-hsx, the same `holder` and `sweep` use.
- **Read-only**: `who` frees no seat whose holder is gone (that stays `sweep`'s, per project), warms nothing, writes nothing, and never migrates a store: a store still at format 1 is read as format 1.
- **It runs anywhere**, inside or outside a git work tree and whatever `memory_require_git` says, since it reads every project rather than the caller's.
- No live seated session prints `no live seated session on this machine`, exit 0.
- Sessions holding no seat do not appear: the stores record only claims.

Why: a person or an agent coordinating work across projects needs to see who holds which seat where, and `sweep` answers for the current project only, freeing seats as it reads. The stores already hold every claim with its session, pid and start time, so the listing costs a directory walk and one liveness check per claim.

Rejected: listing every running `claude` process, seated or not (a process-table scan plus one working-directory lookup per process through `lsof` or `/proc`, with each project guessed from a directory); a flag on `sweep` (`sweep` frees seats, and a machine-wide listing should change nothing in any project); a name such as `agents` or `sessions` (`who` names the question, after the Unix command listing who is logged in).

Accepted costs: a seated session in a project whose store lives under another `CLAUDE_CONFIG_DIR` does not appear; each listed claim costs a `ps` call for its liveness.

Acceptance criteria:

1. A functional test builds two stores under a `t.TempDir()` store root, one claim live and one dead in each (a fake process table), runs `who` from a directory outside git, and gets exactly the two live lines, sorted.
2. After `who`, every claim file, store and cache file is byte-identical, a dead holder's claim included.
3. A format-1 store is listed without being migrated.
4. The MCP tool `who` answers the same text and refuses any key, under the exact-keys rule.
5. With no live claim anywhere, `who` prints `no live seated session on this machine` and exits 0.
6. `README.md` and `agentic-helpers:agent-memory` name `who`.
