An agentic-memory seat follows its session into the new process `claude --resume` or `claude --fork-session --resume` starts: the new process holds its parent session's seat without the agent claiming again, or, where the parent still runs, a seat of its own on the parent's shelf.

Why: a seat is bound to its holder's claude process and start time, and a resumed or forked session runs in a new process, so it starts seatless and the SessionStart notice asking it to claim is easy to skip. A forked session of 97 prompts that shipped two releases filed nothing and left its seat's state slot empty.

How a session finds its parent: a fork's transcript rewrites every record to the fork's own session id and names no parent, but it copies the parent's messages with their uuids unchanged. Every claim records the uuid of its transcript's first message (`first_uuid`), set when the claim is written and by the hook that re-points a claim at a new transcript. At SessionStart a process holding no seat reads its transcript's first message uuid and looks for a claim or last claim carrying it.

- **Parent gone** (plain resume after exit, or a fork after the parent ended): the session takes the seat over, under the seats lock, as a reservation's takeover does (20261025-223640-d-tac-d2p): its process, start time, session id and transcript replace the old holder's, and the brief and replay come back as on a claim.
- **Parent alive** (a fork while the parent runs): the running holder keeps its seat (20261025-164209-d-tac-qj7). The fork gets a new seat on the parent's shelf, named as `claim --shelf` names one, so it reads and writes the parent's memory and files its state apart.
- **No match**: unchanged, the seatless notice.

A session's own claim keeps working as before; the takeover only acts for a process holding no seat. Takeover and child seat say one line, the hook's existing claim header, and nothing else.

Rejected: claiming a seat for every session at SessionStart, named from branch or directory, since it picks seat names for the owner and multiplies seats; reading the parent from the transcript's records, which name none; matching by transcript path, which a fork changes.

Accepted costs: one transcript read at SessionStart for a seatless process in a project with a store; a fork of a running session adds a seat to the shelf.

Acceptance criteria:

1. A resumed session whose parent process is gone holds the parent's seat after SessionStart, with the brief printed, checked by a test.
2. A fork of a running session gets a new seat on the parent's shelf, and the parent keeps its seat, checked by a test.
3. A session whose first message uuid matches no claim gets today's seatless notice.
4. Claims record `first_uuid`; a claim from an earlier release without it never matches.
5. Each guard is broken once and its test watched failing; `docs/memory/` and agentic-helpers:agent-memory describe the takeover in the same change.
