Wherever agentic-helpers tells an agent how to run the grounding searches, it spells `--limit 5 --max-citations 0`: five hits, header lines only, no citation snippets.

    sdd search --query '<subject>' --limit 5 --max-citations 0
    sdd search --term '<literal>' --limit 5 --max-citations 0

**Where.** The gate's refusal text for owed reads (`source/hooks/internal/grounding/refusals/reads.txt`), the reads it names in the let-through note, the `agent-grounding` skill's read block (`plugin/skills/agent-grounding/SKILL.md`), and `docs/grounding-gate/usage.md`. The stream refusal's own example (`refusals/stream.txt`) takes the same flags in place of `--limit 8`.

**Only for bare `sdd`.** A project whose `.sdd/grounding.yaml` names a `read_command` or a `gather_command` gets its reads spelled as today, with no flags added: those commands need not take sdd's flags.

The gate's crediting is unchanged: a search counts as semantic for `--query` and literal for `--term` whatever its limit, and an agent may still read wider.

Why: with no limit named, a search prints ten hits, each a header line carrying the entry's whole summary plus a citation snippet. Five header-only hits measured about 2.8 KB per search on this graph; the gate's purpose is that the agent sees what the graph holds on the subject, which the top hits' headers show. An agent that needs an entry's body reads it with `sdd show`.

Rejected:

- An `sdd search --brief` flag in the sdd fork, printing identity and the first summary sentence as `sdd view`'s `brief` modifier does: work in another repository, waiting on its release.
- Piping searches through `cut`: cuts mid-word, drops status and topics, and is a convention no command enforces.

Accepted costs:

- A header line still carries the full summary, about 550 bytes per hit.
- Five hits can miss an entry a sixth would have shown; the agent widens the search where the subject is broad.
- Projects with their own read command get no smaller output from this.

Acceptance criteria:

1. A refusal for owed reads in a project without `read_command` spells both searches with `--limit 5 --max-citations 0`; with `read_command` or `gather_command` set, the spelling is unchanged.
2. The stream refusal's example search carries `--limit 5 --max-citations 0`.
3. A search with `--limit 5 --max-citations 0` is credited as semantic or literal exactly as one without the flags.
4. `agent-grounding`'s read block and `docs/grounding-gate/usage.md` spell the flags, and the skill says to widen with a higher `--limit` where the subject is broad.
