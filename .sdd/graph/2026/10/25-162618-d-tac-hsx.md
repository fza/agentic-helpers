title: Locale-safe seat liveness check
summary: Seat liveness compares process start instants read under LC_ALL=C instead of locale-dependent ps text. A stored started that parses as neither RFC 3339 nor C-locale ps text is skipped, so the process check alone decides. It refines RFC 3339 UTC stored times (20261025-152555-d-tac-86k), since ps text stored under an unknown locale cannot be parsed, and ships as a patch release ahead of every other agentic-memory change.
---

A seat's liveness check never compares `ps` text across locales. `process.StartTime` runs `ps -p <pid> -o lstart=` under `LC_ALL=C` and returns the instant. `seat.Alive` holds a seat alive when its pid runs the owner command (`claude`) and, where the stored `started` parses as RFC 3339 or as C-locale `ps` text (`Mon Jan _2 15:04:05 2006` in the local zone), the two instants are equal. A stored `started` that parses as neither, such as the German `Sa. 24 Okt. 14:35:50 2026`, is skipped: the process check alone decides. The holder's next claim stores `started` as RFC 3339 UTC, as 20261025-152555-d-tac-86k sets. This ships as a patch release ahead of every other change to agentic-memory.

Why: `ps` prints `lstart` in the caller's locale, so a seat claimed from a German shell reads `alive: false` to every caller under `C` or English, while its process runs. `agentic-memory holder main --json` in fdbox answers exactly that for a live holder today, and fdbox's board reads such an answer as a free seat. Go's standard library parses only English month and day names, so the reader of earlier `ps` text that 20261025-152555-d-tac-86k promises cannot read a store claimed under another locale.

Rejected: parsing German and English names (every other locale still reads dead, and the table grows with each user's locale); rerunning `ps` under every installed locale until one matches (one process per locale per check, and it depends on what the machine has installed); waiting for the format-2 migration to fix it (a live seat reads free until that release).

Accepted costs: until its holder claims again, a seat with an unparseable `started` passes for alive when its pid is reused by another `claude` process.

Acceptance criteria:

1. `process.StartTime` runs `ps` with `LC_ALL=C` and returns a `time.Time`; a test drives a fake process table returning C-locale text.
2. A table-driven test of `seat.Alive`: RFC 3339 `started` equal and unequal to the process start, C-locale `ps` text equal and unequal, German `ps` text with the pid running `claude` (alive), and any `started` with the pid running something else (dead).
3. A claim writes `started` as RFC 3339 UTC.
4. Released as a patch version before any other agentic-memory change listed in the graph.
