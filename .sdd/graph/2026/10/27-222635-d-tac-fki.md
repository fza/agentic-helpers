agentic-memory's Stop and SessionEnd hooks write a mechanical draft of the seat's state slot themselves wherever no state the agent wrote is newer than the seat's claim, so a seat's state is never empty; the agent's own state write always replaces the draft.

Why: only the agent writes the state slot (20261026-215042-d-tac-g5a), and a seat's slot was found empty after several sessions of work on it. What changed is mostly mechanical and known to the hooks; under the owner's rule that hidden messages stay as scarce as possible, a hook that can do the work itself does it rather than asking.

The draft:

- **Body**: the commits since the claim (`git log --oneline <claim commit>..HEAD`, capped), the files the session wrote (the memory tool hook's Edit, Write and NotebookEdit calls), and the last user prompt, cut to the word limit.
- **Marked**: the `state` row gains `draft: true`; the brief opens it `state (<age> old, branch <b>, hook draft): <body>`, and `brief --json` carries `draft`.
- **Never over the agent's**: a draft is written only where the slot is empty, a draft, or older than the claim of a seat the session holds (the seat and its claim as 20261025-164209-d-tac-qj7 describes). The fold never lets a draft replace a non-draft state the same session wrote, so a hook racing the agent's write cannot clobber it.
- **Quiet**: writing a draft prints nothing. A draft does not count as a state write for the compaction nudge (20261026-215042-d-tac-g5a), the replay nudge (20261025-192326-d-tac-303), or the Stop hold that asks for state once work shipped.
- **Beside the replay**: the claim's replay of the previous session's last turns stays as it is; the replay carries what was said, the draft what changed.

Rejected: a draft at every Stop overwriting the agent's state, which loses the judgment the agent wrote; leaving the slot empty and only asking more often, which spends hidden messages on mechanical facts; a draft from the transcript tail alone, which repeats the replay.

Accepted costs: a mechanical draft can read as more authoritative than it is, which its mark answers; one `git log` at Stop and SessionEnd for a seated session.

Acceptance criteria:

1. A seated session that never writes state leaves a draft after Stop, marked in the brief and in `brief --json`.
2. An agent-written state newer than the claim is never replaced by a draft, checked against a concurrent write.
3. A draft is replaced by the next agent state write and counts for no nudge.
4. Writing a draft prints nothing.
5. Each guard is broken once and its test watched failing; `docs/memory/` and agentic-helpers:agent-memory describe drafts in the same change.
