agentic-helpers is a set of machine-wide Claude Code hooks (carry-forward, scratch sweep, grounding gate) and the `agentic-capture` command, each paired with a skill that explains it to the agent. A project opts into each by carrying the directory it works on: `.memory/` for the carry-forward, `.tmp/` for the scratch sweep, `.sdd/` for the grounding gate and capture. A project without the directory is left alone, the binary exiting silently and creating nothing.

The grounding gate and `agentic-capture` exist for sdd, the Signal-Dialogue-Decision graph under `.sdd/`: the gate holds an agent to real `sdd` reads before it asks or drafts, and capture writes a draft through `sdd new`. A project names its topic prefix and draft lint in `.sdd/grounding.yaml`.

Everything ships as one Claude Code plugin from this repository, which is its own marketplace: `.claude-plugin/` holds the manifests, `hooks/hooks.json` the hook wiring, `skills/` the skills, named `agentic-helpers:<skill>`. The hooks and the command are Go binaries built from `source/hooks`; each release publishes them, and `hooks/run` runs the release the plugin's version names, fetching it at SessionStart. `go install -C source/hooks ./cmd/...` builds them for development and for scripts outside Claude Code. The README carries install steps and the full behaviour of each piece.

It supersedes 20260925-155757-s-cpt-iet, which described the binaries built into `~/go/bin` and wired by `agentic-install`.
