`internal/process` reads the process table through the kernel instead of spawning `ps`: on darwin through `golang.org/x/sys/unix.SysctlKinfoProc("kern.proc.pid", pid)`, which returns the parent pid (`Eproc.Ppid`), the process name (`Proc.P_comm`) and the start time (`Proc.P_starttime`) in one call; on Linux through `/proc/<pid>/stat` (fields 2, 4 and 22) with the boot time from `/proc/stat`, standard library only. `golang.org/x/sys` becomes a direct requirement of `source/hooks`; it is already in the module graph through `mvdan.cc/sh/v3`.

Why: every seat lookup, the owning-process lookup of 20261025-021209-d-tac-1pj, walks up to twelve ancestors with two `ps` spawns per level and two more per claim checked (`process/process.go:28`, `:58`; `seat/seat.go:283-336`), and it runs on every guarded call of the grounding gate (`grounding/grounding.go:767`) and in agentic-memory's and agentic-tools' hooks. One `ps` costs about 5 ms, so a lookup spends 20 to 40 ms forking before any work. The `lstart` text the locale-safe liveness check (20261025-162618-d-tac-hsx) reads needs `LC_ALL=C` and a parser of its own, which a kernel read does not.

Mechanics:

- One file per OS, `process_darwin.go` and `process_linux.go`, behind the existing functions, so callers do not change.
- Start times are truncated to whole seconds, matching what claims record. Linux start time is computed from boot time plus ticks at `CLK_TCK` 100.
- The `lstart` parser stays only to read claims written by earlier releases (`seat.go:325-336`) and goes once no supported release writes them.
- `P_comm` is truncated to 16 bytes; the owner walk compares against `claude`, which fits.
- The doubled parent-and-name read per ancestor level in `seat.go:287-292` becomes one.

Rejected alternatives:

- `github.com/shirou/gopsutil/v4`: about seven modules for three fields, still shells out to `ps` on darwin for status, loads libproc through purego, and has gone through three major versions.
- `github.com/mitchellh/go-ps`: archived, and gives no start time.
- Keeping `ps`: the cost is paid on every guarded hook call.

Accepted costs:

- A direct `golang.org/x/sys` requirement and two build-tagged files.
- Linux start time rests on `CLK_TCK` being 100.

Acceptance criteria:

1. `go vet ./...` and `go test -race ./...` pass on darwin and Linux; the binaries spawn no `ps` (checked by a test with a PATH holding a `ps` that fails).
2. A table-driven test of the Linux `/proc/<pid>/stat` parser over fixture files, including a process name with spaces and parentheses.
3. A claim written by the previous release still reads as alive or dead correctly.
4. `docs/memory/architecture.md` names the kernel read, in the same change.
