A seat claim turns Claude Code's own auto memory off for its project, and agentic-scratch and agentic-memory add `.tmp/` and `**/.claude/settings.local.json` to git's global excludes file, in agentic-helpers commits 619c2cf, 2d8fc57 and 85e2456, not yet released, completing 20261026-212952-d-tac-tyn and 20261026-213516-d-tac-vrp.

`internal/gitignore` resolves the global excludes file and appends a pattern where `git check-ignore` does not ignore the path; agentic-scratch's `start` and agentic-memory's claim call it. `internal/memory/automemory.go` adds `"autoMemoryEnabled": false` after the opening brace of the main checkout's `.claude/settings.local.json`, keeping every other key and the text around them. The claim for another session does the same, so the reserved session starts with auto memory already off. The plugin option `memory_turns_off_auto` sits in `plugin.json`, `pluginconfig` and `README.md`'s Options.

Beyond the decisions' criteria, commit 85e2456 answers a security review of the write: a repository can carry `.claude/` or the settings file as a symbolic link to anywhere, so a claim refuses to write where either is one, naming it, and replaces the file through a temporary one opened exclusively under a random name rather than a name derived from the process id.

Every criterion of both decisions holds with a test, except one part of 20261026-213516-d-tac-vrp's fifth: a project without `.tmp/` is shown to write nothing, while the count of git calls is not asserted; agentic-scratch's `Main` returns before calling git when `.tmp/` is missing. Tests use a fake git and a temporary home throughout.

Each new check was disabled in turn, its test watched failing, and the source restored byte for byte.
