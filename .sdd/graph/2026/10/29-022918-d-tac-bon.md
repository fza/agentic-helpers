The agentic-memory inferred end "every link ended" (`inferredEnd` in `source/hooks/internal/memory/ends.go`), which puts an entry under `retire?`, no longer counts a memory target the entry itself superseded, and never applies a todo's links to memory entries. It narrows the inferred end that 20261026-215617-d-tac-45q set as "every link target closed, superseded, retired or gone".

- A memory target superseded by this entry never counts as ended.
- A todo's links to memory entries never infer its end; only its graph links do, since a todo ends by its own work.
- Traps and notes keep inference from memory links: a trap linked to its fix todo, or a note linked to the todo it measured, is flagged once that todo ends.
- Agents see no new rule; the skill text changes only as far as 20261029-022655-d-tac-u8e changes it, which sets where candidates print while this entry sets which entries become candidates.

The choice follows the token-cost criteria of 20261029-021515-d-tac-00q: least risky first (agents informed, no mistakes, rules obeyed), fewest tokens second.

Why: 4 of 5 `retire?` candidates in a measured brief were false, every one a todo linking back to its predecessor, retired or superseded by the todo itself. False flags cost tokens and invite retiring todos that are still live.

Rejected: inferring from graph links only (a fixed trap would never be flagged, and agents keep obeying a stale trap up to its 90-day half-life); skipping only the entry's own successor (holds only while agents supersede rather than retire a replaced request, and one slip brings the false flags back).

Accepted cost: a todo whose memory target ended is not flagged; it decays at its 3-day half-life.

Acceptance (tests):
- A todo linking only to a retired memory entry is no candidate.
- A trap linking a retired todo is a candidate.
- An entry linking a memory target it superseded does not count that link as ended.
- A todo with a closed graph link is a candidate.
