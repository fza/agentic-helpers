Where `timeout` is missing, shell-guard rewrites `timeout N cmd` to `agentic-helpers bound N cmd`, a new subcommand of the plugin's own `agentic-helpers` binary, and offers nothing else: `gtimeout`, `uu-timeout` and the perl alarm form leave the chain.

Why: the last fallback of the command alternatives (20261029-125259-d-tac-5n4), `perl -e 'alarm N; exec @ARGV' cmd`, bounds nothing for a Go program. The alarm survives the `exec`, and Go's runtime catches `SIGALRM` and ignores it, so `go test`, every agentic-helpers hook and any other Go tool run unbounded behind it. Verified on macOS 27.0: a Go program sleeping 6 seconds ran its full 6 under `alarm 2`, while `sleep 6` stopped at 2 with exit 142. A bound that silently does not bound is worse than none, since the agent trusts it.

**`agentic-helpers bound <duration> <command> [args...]`.**
- The duration as GNU `timeout` spells it: a number of seconds, optionally with `s`, `m`, `h` or `d`, so the rewrite copies it unchanged.
- Starts the command in its own process group, with standard input, output and error passed through.
- At the bound, sends `SIGTERM` to the whole group, then `SIGKILL` to the group 5 seconds later if any of it still runs, so a `go test` and the test binaries it started all end.
- A `SIGINT` or `SIGTERM` that `bound` itself receives goes to the group.
- Exit status: the command's own; 124 when the bound ran out, as GNU `timeout`; 125 when `bound` itself fails (bad duration, no command), 126 or 127 when the command cannot run or is not found, as GNU does.

**Shell-guard.**
- Refusal: `agentic-shell-guard: timeout is not installed here; use: agentic-helpers bound <duration> <command>`, built from the parsed command as today.
- `agentic-helpers bound` joins `internal/shellwalk` as a launcher with two fixed words, so the command behind it is judged as behind `timeout`.
- `gtimeout`, `uu-timeout` and `perl -e 'alarm N; exec @ARGV'` stay launchers the walk understands, since an agent may still type them; the rewrite no longer names them.
- `timeout` options with no `bound` equivalent (`-s`, `-k`, a duration built at run time) keep today's refusal shape: the rewrite without them, for the agent to write itself.
- The `agentic-helpers` SessionStart line names `timeout -> agentic-helpers bound` where `timeout` is missing, as it names any substitution.

**Rejected.**
- Keep `gtimeout` and `uu-timeout` first, the bound command last: the rewrite then differs by machine and shell-guard recognises four forms for one job, while `bound` needs nothing installed.
- A perl form that forks, puts the command in its own group and kills the group: no graceful stop, so a killed `go test` leaves its temporary files; about 25 tokens of punctuation an agent must copy exactly; and a longer perl program shell-guard would have to allow as inline code, where any edit turns it into code it cannot judge.
- Dropping the fallback for an install hint (coreutils' `gtimeout`): until it is installed no run can be bounded.
- A bare `timeout` shim in `bin/`, rejected by 20261029-125259-d-tac-5n4: still rejected. `bound` is a subcommand of the `agentic-` prefixed binary, so nothing on PATH shadows a system tool.

**Accepted costs.** A subcommand to maintain. The command runs in a group of its own, so one reading a terminal would stop on `SIGTTIN`; agents' Bash calls have none. The bound's exit on expiry changes from 142 to 124, and the skill and docs change with it. Where `agentic-helpers` is not on PATH (the plugin's `bin/` absent), the rewrite names a command that does not run; shell-guard runs only as that same plugin, so both arrive together.

**Acceptance.**
1. `agentic-helpers bound 2 <go program sleeping 6s>` ends after about 2 seconds with exit 124; the same with `sleep 6`; a command exiting 3 within the bound exits 3.
2. A command that ignores `SIGTERM` is killed 5 seconds after the bound; a child the command started ends with it.
3. A `SIGTERM` sent to `bound` reaches the command's group.
4. A bad duration exits 125 naming it; a missing command exits 127.
5. Without `timeout` on a fake PATH, `timeout 9 go test ./...` is refused with the `agentic-helpers bound 9 go test ./...` rewrite, whether or not `gtimeout`, `uu-timeout` or perl are present; with `timeout` present, nothing is refused.
6. `agentic-helpers bound 9 rm -rf ~/x` gets the outside-project verdict, `agentic-helpers bound 9 rm -rf ./build` runs, and `gtimeout 9 rm -rf ~/x` and the perl alarm form still get the outside-project verdict.
7. The `agentic-helpers:agent-shell-guard` skill and `docs/shell-guard/` name the new rewrite and its exit 124; `docs/plugin/` describes `bound`.
