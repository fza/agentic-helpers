When the user asks for a seat in a new session, in any wording or language ("claim main seat", "main seat", "Haupt-Session", "Beanspruche Haupt-Session"), the agent claims it and answers with a short overview of where work stands, written from the brief the claim printed: the seat's state slot (the one overwritten note of where its work stands), what is due, open todos with their next items, and open questions or decisions waiting on the user. Written in the user's language, outcomes only, no entry ids or titles unless one names work the user has to act on.

The `agentic-helpers:agent-memory` skill carries the rule: its quiet section, which forbids a recap of the brief or claim output, gains this exception for a claim the user asked for, and its seat section says what the overview holds. `docs/memory/usage.md` states the same.

Why: claiming a seat is how a session picks up earlier work, and the brief that holds where it stands reaches only the agent. Under the quiet rule the user got no answer to what is, in effect, "where were we?". Matching a loosely named seat already works (`who`, then the seat whose name means the same), so only the reply was missing.

**Rejected.**
- `agentic-memory claim` printing a fixed overview block for the agent to relay: the same text every time, but a new output contract to keep with its tests, English only or carrying a language rule of its own, and an echo of what the brief already says.
- A prompt hook detecting a claim request: matching intent across languages in a hook is guesswork, and the skill already maps loose names.

**Accepted costs.** The overview's wording varies by agent, and an agent ignoring the skill shows none. A claim at SessionStart on resume, or one a launcher makes, is not a request from the user and gets no overview.

**Acceptance.**
1. The skill's quiet section names the exception, and its seat section lists what the overview holds.
2. `docs/memory/usage.md` says the same.
3. A new session told "Haupt-Session" claims seat `main` and answers with the overview in German.
