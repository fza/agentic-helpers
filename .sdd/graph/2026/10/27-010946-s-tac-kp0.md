Agentic-memory traps tell the agent at the tool call that touches them, and rules filed `--on claim` or `--on compact` are tracked as do-now items, in one agentic-helpers commit, 80a38ee, not yet released, completing 20261026-220335-d-tac-nu3 and 20261026-220743-d-tac-8lf.

Trap triggers, each criterion with its test in `internal/memory/`:

1. `--when` takes `path:`, `command:` and `tool:`, refuses a malformed trigger, an invalid pattern and another kind: TestWhenTakesEachTrigger. MCP fills the same request; no test sends a malformed trigger over MCP.
2. The match over anchors, each form and every input field: TestATrapIsTouchedBy.
3. Once per session, again after compaction: TestATrapIsToldOncePerSession.
4. Received traps trigger: TestAReceivedTrapTriggers.
5. No traps, no trap state read: TestASeatWithoutTrapsReadsNoTrapState.
6. Docs and agentic-helpers:agent-memory name `--when`, each form and the notice.

Do-now rules:

1. `--on` and `--proof` belong to a rule, malformed triggers refused: TestOnAndProofBelongToARule.
2. The numbered list first, for that trigger only: TestDoNowAtClaim.
3. A proving call after the trigger settles the item, one before it does not: TestAProofBeforeTheMomentProvesNothing.
4. `ack --done` and `--decline`, all or nothing, a non-pending id refused: TestAckSettlesPendingItems.
5. Stop holds at most twice before the backstop: TestStopHoldsTwiceThenSkips.
6. Skipped items in the next brief: the same test.
7. Docs and the skill name `--on`, `--proof`, `ack` and the wording.
