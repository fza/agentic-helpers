The carry-forward's `stop` takes each turn's final reply from the Stop payload's `last_assistant_message`, not from the harness transcript, so the session log under `.memory/transcripts/<session>.md` files every reply under the prompt that asked for it.

Claude Code may write a turn's final reply to the harness transcript only after the Stop hook has read it; its hook documentation says the transcript is not guaranteed to hold the final message at Stop time and points hooks acting on the finished turn to `last_assistant_message`. Reading only the transcript, `stop` logged each turn with the right prompt and the previous turn's final reply, since that late reply opened the next read.

- `hookio.Payload` reads `last_assistant_message` into `LastReply`.
- `stop` passes it to `appendTurn`. `turnBlock` drops trailing assistant text the final reply already contains and appends the final reply, so a transcript that does hold it logs it once.
- The session's `.state` file keeps the logged final reply under `last_reply`. Assistant text opening the next read, ahead of any user record and contained in `last_reply`, is the late copy and is dropped.
- The log stays markdown. Its only readers are models: `session-log` inlines it after a compaction in pieces under the client's inline limit, and the seat folds it into its carry-forward memory. No code parses it.

Rejected:
- Logging the turn at the next `UserPromptSubmit`, when the transcript is complete. The last turn before a compaction or session end would never be logged, and that is the turn a compaction most needs.
- Waiting inside `stop` until the transcript grows a final reply. It adds latency to every turn and still guesses when to stop waiting.
- A JSONL log. JSON escaping and keys lengthen every turn, so fewer turns fit the pieces `session-log` inlines; one record per line often exceeds a piece and would be cut into invalid JSON; and no consumer parses the log.

Accepted costs:
- Logs written before the change keep their shifted replies.
- `last_reply` holds one reply's text in the state file.
- A turn carrying no prompt whose leading text the previous reply happens to contain loses that text.

Done when `go test -race ./...` passes in `source/hooks` with a functional test of a transcript lagging at `stop` and one already holding the reply, and `go install -C source/hooks ./cmd/...` has rebuilt `agentic-carryforward`.
