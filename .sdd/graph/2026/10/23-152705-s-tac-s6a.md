Done for 20261023-150359-d-tac-s8g: agentic-helpers requires sdd from github.com/fza/sdd. Commit 2d1fc1f, released as v1.2.0 (release commit 87dbf6d).

- `source/hooks/internal/sddfork` runs `sdd --version` bounded at 5 seconds and calls it the fork only where it exits 0, opens with `sdd version ` and carries `fza` after it; nothing else of the version is parsed.
- `agentic-capture` checks after the header and before the lint, the pre-flight and the capture, and exits 1 with `agentic-capture needs sdd built from github.com/fza/sdd; \`sdd --version\` printed <output>. Install it with \`brew install fza/tap/sdd\`` where it is not the fork.
- The grounding gate checks at SessionStart in a project carrying a graph; without the fork it prints `agentic-helpers: the grounding gate is off for this session, ...` once to stdout, writes `<session>.unforked.json` beside the session's ledger, and passes every gated call of that session. The session's end and the orphan reap remove the record with the ledgers.
- Tests: a capture refused for upstream, a dev build, another program printing `fza`, a failing fork-shaped sdd and no sdd at all, with nothing but the version run; a capture through a fork release and a local fork build; the gate's notice and record without the fork, a call passing that is refused without the record, another session still gated, the record gone after the end; the fork raising no notice and keeping the gate; a project without a graph never running sdd. The capture check, the `fza` match, the `sdd version ` prefix, the exit-code check, the gate's start check, its pass, the record's removal and the fork's exemption were each broken and watched failing on their own tests.
- `README.md` opens with Installing: the fork through `brew install fza/tap/sdd` or its install script pinned to `v0.18.0-alpha.2.fza.22`, then the plugin; every sdd link points at the fork; both skills state the requirement, the refusal and the notice.
- On this machine every session, fdbox's board and its capture agents resolve `~/go/bin/sdd` (`0.18.0-alpha.2+fza21`) before the upstream `/opt/homebrew/bin/sdd` (0.17.0), so nothing in flight was refused.
