Each agentic-helpers piece keeps the files it writes out of every repository by adding their pattern to git's global excludes file, at the moment it relies on the file being untracked: agentic-scratch adds `.tmp/`, agentic-memory adds `**/.claude/settings.local.json`.

- **The file** is git's own: `core.excludesFile` from the global git config, a leading `~/` expanded, else `$XDG_CONFIG_HOME/git/ignore`, else `~/.config/git/ignore`, as git resolves it. A missing file is created, its directory with it.
- **agentic-scratch** checks at its `start` hook, in a project carrying `.tmp/` (where it already works): where `git check-ignore` does not ignore `.tmp/`, `.tmp/` is appended.
- **agentic-memory** checks when a claim writes `autoMemoryEnabled: false` into `.claude/settings.local.json` (20261026-212952-d-tac-tyn): where `git check-ignore` does not ignore that file, `**/.claude/settings.local.json` is appended. This replaces the repository's `info/exclude` step that decision named; nothing writes `info/exclude`.
- **A pattern already in the file**, or a path git already ignores by any rule, adds nothing. An addition is said once: `<piece>: added <pattern> to <file>, so git ignores it in every repository`.

Why: `.tmp/` holds a session's throwaway and drafts, and `.claude/settings.local.json` holds one person's settings for a project; both are wrong in a commit, in every repository the pieces run in. Claude Code ignores its local settings file only when it creates it itself, and the `agentic-helpers:agent-scratch` skill requires `.tmp/` to be ignored without anything making it so.

Rejected:

- One place for both patterns, `agentic-helpers check` at every session start: writes a pattern for a piece that may be off or never used on the machine.
- The same behind a plugin option `global_gitignore`: one more option for a write that only adds what git would otherwise track by mistake.
- The repository's `info/exclude`: covers one checkout; every clone and every new repository needs it again.
- A project `.gitignore` entry: a change to a shared, committed file, made by a tool on one person's machine.

Accepted costs:

- The plugin writes a user-wide git file, affecting every repository on the machine, as intended.
- A machine whose global excludes file is managed elsewhere (dotfiles) gains a line it may overwrite later; the next session adds it again.
- `.tmp/` is ignored in every repository, including one that tracks a directory of that name on purpose.

Acceptance criteria:

1. With `core.excludesFile` set, scratch's start in a project carrying `.tmp/` that git does not ignore appends `.tmp/` to that file and prints the line once; a second start adds and prints nothing.
2. With no `core.excludesFile`, the pattern lands in `$XDG_CONFIG_HOME/git/ignore`, else `~/.config/git/ignore`, the file and its directory created.
3. A project whose own `.gitignore` already ignores `.tmp/` adds nothing.
4. A claim writing `.claude/settings.local.json` appends `**/.claude/settings.local.json` where git does not ignore the file, and writes no `info/exclude`.
5. A project without `.tmp/` runs no git and writes nothing from scratch's start.
6. Tests fake git and use a temporary home; no test reaches the developer's git config.
7. `docs/scratch/*`, `docs/memory/usage.md`, `agentic-helpers:agent-scratch` and `agentic-helpers:agent-memory` say what is added and where.
