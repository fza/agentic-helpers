Done for 20261025-194433-d-tac-8qe: commit 2f57e1c, released as v2.5.0 (release commit 2be0a48).

- `writers.json` lists git common directories; under the store lock a write is checked against it, an unlisted store claimed by the writer, and a list that cannot be read refuses everyone. `agentic-tools trust <path>` (MCP `trust`, key `path`) adds a checkout from a listed one. A checkout not listed takes only into its own `.tmp/`, recording nothing, and its hooks stay silent.
- Judgment calls within the decision: a read that rebuilds a missing index writes it back and so claims an unlisted store for the reading project, which is how fdbox's renamed library is claimed by fdbox; a take from a checkout not listed is refused where the checkout has no `.tmp/`, since its copy would otherwise land in the store.
- Also in the commit: a worktree's own top is in the registration reach, which before resolved only the main checkout.
- Tests: `writers_test.go` covers every criterion; the per-path fake `test.GitDirOf` answers several checkouts and worktrees. Every guard was broken and caught; `claim`'s own list check is masked by the writer check before it and reachable only by a race.
- Docs: `docs/tools/usage.md`, `docs/tools/architecture.md` and `agentic-helpers:agent-tools`.
