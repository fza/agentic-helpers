agentic-memory's near-compaction nudges measure the context against the compaction window Claude Code itself settles, which the plugin's mod reads each turn and writes beside the context reading.

**Writer.** `plugin/hooks/register.ts`, on `session.measure` (20261025-031151-d-tac-klv), calls `$.session.usage({ breakdown: 'summary' })` and adds `compact_window` (the breakdown's `rawMaxTokens`) to the `.ctx` reading beside `used_percentage` and `size`. Where the call is missing or throws, or the breakdown is absent, the key is left out and the reading is written as before; the event is always passed on.

**Reader.** `contextPercent` in `source/hooks/internal/memory/hooks.go` rescales the reading to `compact_window` when the reading carries one smaller than `size`; else to `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, as today; else it reads the share of the full window. The nudge thresholds stay as they are.

Why: the gap 20261029-023926-s-tac-y8f found the first nudge rung sitting past the point where Claude Code compacts whenever the window is set in settings rather than the environment. Claude Code settles the window from the environment variable, the `--autocompact` flag, `modelSettings[<model>].autoCompactWindow`, a top-level `autoCompactWindow`, the account and experiments, and its mod API hands the result over as `rawMaxTokens`, naming where it came from as `autocompactSource`. Reading that one figure can never disagree with Claude Code. `summary` estimates the breakdown locally and sends no request.

Rejected: resolving the window in Go from the settings files for the session's model. It copies Claude Code's lookup order, which drifts when that changes, has to merge every settings scope, and cannot see the `--autocompact` flag, the account or an experiment at all.

Accepted costs: a local estimate of the context breakdown on every main-thread turn; the plugin depends on one more mod API name (`session.usage` and its `breakdown.rawMaxTokens`); a Claude Code without the call keeps today's behaviour, as 20261027-174929-d-tac-3q0 requires of older releases.

Acceptance:
1. `register.test.ts`: a usage answer carrying a breakdown writes `compact_window`; a missing call, a throwing call and a breakdown-less answer each write the reading without it; every case calls `next`.
2. A table-driven Go test of `contextPercent` covers a reading with `compact_window`, one without it with and without the environment variable, and a `compact_window` not smaller than `size`.
3. Verified live: in a session whose window comes from `modelSettings`, the `.ctx` file carries that window.
4. `docs/memory/architecture.md` and agentic-helpers:agent-memory describe the reading and its fallbacks in the same change.
