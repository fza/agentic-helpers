The grounding gate lets `sdd new --help`, `sdd new -h`, `agentic-capture --help` and `agentic-capture -h` through without owing the reads, in agentic-helpers commit eb10a46, not yet released. It builds on the spelling recognition of 20260925-193337-d-tac-9jv, which exempted only `--dry-run`: an agent reading `sdd new`'s usage before its first capture drew `GROUNDING GATE: refused`. One pattern now names every flag that makes either call write nothing, and `agentic-capture` is checked against it as `sdd new` was; a help call chained before a real capture still owes the reads. `docs/grounding-gate/usage.md` and `agentic-helpers:agent-grounding` list the flags. Each new guard was broken, its test watched failing, and the file restored byte-identically.
