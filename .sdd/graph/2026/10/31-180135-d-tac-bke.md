Each memory store rewrites the scratch paths its entries quote in place, once, so entries keep working after the scratch move of 20261031-175124-d-tac-vw1 on every machine running agentic-helpers. Entries quote paths such as `.tmp/claude/main/state-nudges.sh` or `.tmp/claude/todos/`; after the move they point at nothing, and an agent reading one sees at best `gone: <path>` with no hint where the file went.

**Pass.** The first memory call of the release on a store, under the store's lock, copies `log/` to `memory/backup/scratch-paths-<UTC stamp>/`, rebuilds the log through a migration pass that rewrites path text in every entry's title and body, every todo item's text and every seat's state, swaps the rebuilt log in, and writes a marker file `memory/scratch-paths.json` last, so the pass runs once and an interrupted run starts over from the backup. Ids, links, heat, anchors' targets and history stay; a changed entry is re-embedded and re-anchored to its new paths. The store's format stays 7: the pass changes text only, so an older release still reads the store, where a format bump would lock it out with `ErrNewerStore`.

**Mapping, by rule.** `.tmp/claude/<seat>/...` becomes `.tmp/seats/<seat>/...` for a seat of the store, `.tmp/claude/<session-id>/...` becomes `.tmp/seats/<session-id>/...`, and any other `.tmp/claude/<name>...` becomes `.tmp/keep/<name>...`. The rule, not a record of moves, decides, because the scratch move runs per checkout and waits 24 quiet hours for strays while the store pass runs once for every checkout sharing the store.

**Rejected.** Superseding each affected entry with a corrected copy: ids change, so links, notes and graph links naming the old id would have to follow, and a hook would file entries into every seat's shelf. Rewriting what memory prints while the store keeps the old text: every read pays a lookup, and the stale text stays in exports and searches. A new event kind for body edits: an older binary reads an unknown kind as a corrupt log. Leaving entries to the `gone:` flag and agents' upkeep: the flag says nothing about where a file went.

**Accepted costs.** A stray whose name was already taken in `.tmp/keep/` and moved with a suffix is mapped to the unsuffixed name. A log rebuild and re-embedding of changed entries once per store. Text an older release writes after the pass still names old paths.

**Acceptance.**
- After the pass, a live, retired or superseded entry naming `.tmp/claude/<seat>/x`, `.tmp/claude/<session-id>/x` or `.tmp/claude/<name>` reads with the mapped path in title, body, todo items and state; its id, links and heat are unchanged.
- The backup holds the log as it was; the marker stops a second run; an interrupted run leaves the store readable and reruns.
- `format.json` stays 7, and a format-7 binary without the pass reads the rewritten store.
- Changed entries are re-embedded and re-anchored.
- `docs/memory/architecture.md` describes the pass and its backup.
