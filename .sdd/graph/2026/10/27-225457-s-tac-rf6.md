The memory and tools MCP servers describe every call in the words of its keys, shipped in agentic-helpers commit b36b6a8, not yet released. This closes the key-worded descriptions directive (20261027-225155-d-tac-0gp).

- Tool descriptions carry no command-line form (`internal/memory/mcp.go`, `internal/tools/mcp.go`); the command descriptions are reworded without flags, so CLI `help` reads the same text beside its usage line.
- Every input key of both servers carries a description; a key naming entries says whether it takes one string (`id`) or an array even for one (`ids`).
- `supersede` takes `by` and `because` together and refuses only neither (`supersede needs --by <id>, --because '<why>' or both`); `show`, the status flag and the event note read `superseded <stamp> by <id>: <why>`.
- Criterion 1: `TestEveryToolDescribesItsCallInKeys` in both packages, through `test.UndescribedInputs`; it found `unlink` still naming `--link`, now reworded. Criterion 2: `TestSupersedeTakesASuccessorAndAReasonTogether` and `TestSupersede`. Criterion 3: seven guards broken (CLI form on each server, a missing key description on each server, the old exclusivity, the needs-one refusal, the reason in the rendered line), each failing its own test, each file restored byte-identically; `docs/memory/usage.md`, `docs/tools/usage.md` and agentic-helpers:agent-memory updated in the same commit.
