`embedding_provider` is a picker of `auto`, `openai`, `ollama` and `off` that takes over `embedding_source`, built in agentic-helpers commit cf2a59d, not yet released, closing 20261030-175918-d-tac-iwd and the picker list of 20261030-180216-d-tac-66x.

**Built.** `internal/pluginconfig` reads the provider as a picker with built-in default `auto`; `EmbeddingFromSdd` returns false for `off` first, then follows sdd under an `sdd` source or under an `auto` source with provider `auto`; `OwnEmbedding` hands embed no provider for `auto` and `off`. A new list `Undeclared` holds `embedding_source`, read from every layer but no longer declared, and kept out of `ConfigOnly`, which would drop saved dialog answers. `plugin.json` declares the provider picker with default `auto` and no `embedding_source`. At session start, a layer still setting `embedding_source` gets `agentic-helpers: embedding_source is <value> (<layer>) and still applies; embedding_provider replaces it: auto, openai, ollama or off`. README `Options`, `docs/memory/usage.md`, `docs/plugin/usage.md` (the picker list now naming `embedding_provider`, not `embedding_source`) and `docs/tools/usage.md` describe the picker and what `off` stops.

**The rest of 66x stood already.** The other six pickers (`writing_style`, `scratch_sweep`, `shell_guard_outside_project`, `shell_guard_find_delete`, `shell_guard_secrets`, `shell_guard_secret_output`) have declared `options` and the reader's built-in default since the build that closed 20261030-113044-d-tac-is5, unchanged here; README already names Claude Code v2.1.271 as the minimum, and `docs/plugin/usage.md` already stated the picker exception. `claude plugin validate .` passes, and the options test checks every picker's values and that each declared default equals the built-in one.

**Tests**, each guard broken and caught: a 48-case table over provider, source and an sdd block, counting sdd runs and checking `auto` settles as an unset provider did; functional tests driving `memory.Main` and `tools.Main` under `off`, `off` over `sdd` and `own`, proving what stops (search by meaning, prompt recall, tool offers, `find --query`, the near-duplicate check) and what keeps working (keyword search, filing, the byte-identical check); a refused value outside the four; an empty value reading as `auto`; the session-start lines; a set `embedding_source` applying from `config.yaml`, a saved answer, the hook environment and managed settings; an untouched dialog save hiding nothing. The options test now also requires a picker's values to equal the reader's refusal list.

**Proven live** on the installed build in a scratch project: `agentic-helpers config` lists the provider with its layer; with the provider `off`, `search --query` answers `semantic search needs an embedder: no embedding provider configured` while `search --term` finds the entry; the default finds it by meaning; the session-start check names a set `embedding_source`, and under `off` adds no sdd line; a provider `olama` in the hook environment fails the check with `embedding_provider: "olama" is none of auto, openai, ollama, off`.

**Deviations.** `agentic-helpers config` shows the provider as `auto` where it showed an empty value. A provider outside the four in the hook environment refuses that whole layer, so commands fall back to the layer below while the session-start check names it.
