Both plugin MCP servers now leave the `json` key out of their schemas and let it through on tools whose command takes `--json`, completing the directive (20261029-083737-d-tac-kib). The memory server's half shipped in commit 6ad7f0a; the tools server's half is commit 12bcae6, with tests, contract tests over both servers' skills and docs, and the skill and docs changes, not yet released. A live probe of both installed binaries over stdio showed no `json` key on either tools/list, `find` and `list` answering with `json: true` as without it, and `reindex` refusing it with `reindex takes no key "json"`.
