The `agentic-helpers:agent-memory` skill keeps in `plugin/skills/agent-memory/SKILL.md` only what nearly every session uses, rewritten terse, and moves rare topics into files beside it that an agent reads on demand. The skill shipped with agentic-memory (20261025-014326-d-tac-mvn) had grown to 32.3k characters loaded whole every time.

**Core (`SKILL.md`).** Quiet behaviour, seat and claim, `new` and the entry kinds, the state slot, `search` and `show`, `link`, `supersede` and `retire`, lifecycle, and what comes back. Written in the terse style of 20261029-021652-d-tac-xzt.

**Files beside it**, each linked from a "Read when" table in `SKILL.md` naming the reply text or situation that calls for it:
- `shelves.md`: shelves, shared entries (`--for`, `follow`), seat lifetime.
- `triggers.md`: traps, `--about`, do-now rules, `ack`.
- `attachments.md`: `attach`, `read`.
- `view.md`: view layouts.
- `reference.md`: kind and decay overrides, JSON, MCP, the carry-forward file, off on the machine.

Target about 11k characters per load, from 32.3k. Wording that hooks and replies quote stays verbatim.

Why: over three days the skill loaded 49 times in 46 sessions, about 8k tokens each. Usage over the same window: `new` 1424, `state` 508, `show` 269, `link` 182, `supersede` 131, `retire` 128, `search` 124, `who` 117, `claim` 112, `view` 32, `lifetime` 12, `read` 6, `follow` 4. Claude Code loads a skill's supporting files only when the agent reads them, and its documentation advises keeping `SKILL.md` lean with reference material in separate files.

Rejected: splitting only, wording unchanged (about 18k per load); a terse rewrite kept in one file (about 20k, and rare topics still load every time).

Accepted costs: a rare case needs one more `Read`, and an agent skipping it may misuse the command.

Acceptance: `SKILL.md` holds the core topics at about 11k characters; each rare topic lives in its named file, linked from the "Read when" table; every hook and reply string the skill quoted before is still quoted somewhere in the skill's files.
