The subagent memory ladder (20261031-202547-d-tac-xmy) is built in agentic-helpers commit 557f64f on local `main`, not pushed or released, and proven in headless Claude Code sessions loading the plugin from the same tree.

**Surfaces it adds.** `agentic-memory pre-tool` on PreToolUse for `Agent`, `Task`, `Bash` and the memory MCP tools; `agentic-memory subagent-stop` on SubagentStop; a hidden leading `--agent <id>` flag the hook inserts for a `full` subagent and the CLI refuses unless the session's record names that agent at `full`; an `agent` field on stored seat claims that keeps a subagent's seat out of process and session lookups; per-session `agents/<session>` slot records; the agent-memory skill's Subagents section and its reference `subagents.md`.

**Live proof**, with a throwaway home (session logs under `.tmp/seats/main/proof-ladder/runs/`, not tracked); a seat is an agentic-memory identity a session holds, a shelf the memory seats share:
- No marker: the child's prompt opened with only `scratch: .tmp/seats/main/` and the machine line.
- `rules`: the child's block carried the seat's user rule, and the child followed it.
- `silent`: `agentic-memory search` answered; Bash `new` and the MCP `new` tool were both refused with `agentic-memory: the subagent runs at agentic-helpers level silent, which reads memory but never writes it; report what is worth keeping to the spawner instead`.
- `full`: the child's Bash `new` was rewritten with `--agent <id>` and filed on a new seat `main-2` on the parent's shelf; the parent's seat filed nothing; the parent got `agentic-memory: new for main (1): ... [0m, main-2]`; SubagentStop freed `main-2`.
- Nested cap: a `silent` child asking `full` for its own subagent got `silent`.
- No hook output carried `permissionDecision: allow`; the only decisions were the two refusals above.

Shelf notices at the subagent's tool calls for `shared` and `full`, and none for `silent`, are covered by `TestShelfNoticesReachSharedAndFullSubagentsAlone` in `source/hooks/internal/memory/subagents_test.go`; the live runs did not exercise a `shared` child, and showed the notice only in the parent's direction. The same commit describes the ladder in `docs/memory/usage.md` (`## Subagents`), `docs/scratch/usage.md`, `docs/plugin/usage.md`, `docs/plugin/architecture.md`, `docs/memory/architecture.md`, `plugin/README.md` and `README.md`.

Evidence also: `go test -race ./...` in `source/hooks`, `claude plugin validate .` and `claude plugin test plugin` pass; every new guard was broken, caught by its own test and restored byte-identically.

**Choices and costs found.** `none` and `rules` refuse memory reads, as the ladder grants reads only from `silent`. A spawner's prompt quoting a marker line meant for a nested Agent call loses that line, since the rewrite drops every marker line it finds. `agentic-memory pre-tool` adds about 21 ms to each Bash call. A subagent's reads still mark entries shown for the whole session, so the parent later sees them as pointers.
