summary: Agentic-memory mints entry ids as `m-` plus a configurable 6 to 16 characters of `a-z0-9`, defaulting to 6. It builds on the agentic-memory directive (20261025-014326-d-tac-mvn) by widening the ids its store mints, since 4-character ids grow collision-prone as stores fill; ids already filed stay valid and the MCP and CLI schemas accept lengths 4 to 16.
---

agentic-memory mints entry ids as `m-` followed by `entry_id_length` characters of `a-z0-9`. `entry_id_length` is a `userConfig` number in `plugin/.claude-plugin/plugin.json` beside `entry_max_words`, read by `internal/pluginconfig`: default 6, which is also the minimum, a value below 6 read as 6, one above 16 read as 16. Each character is drawn without modulo bias: a random byte at or above 252 (the largest multiple of 36 that fits a byte) is drawn again.

An id already in a store keeps working whatever its length: the 4-character ids minted before stay valid, and so does every id minted under an earlier setting. Every MCP tool schema taking an id (`idSchema`, `internal/memory/commands.go`) accepts `^m-[a-z0-9]{4,16}$`, and the CLI accepts the same.

Why: 36^4 is about 1.7 million ids, and the 64-draw collision retry grows likelier as a store fills; 36^6 is about 2.2 billion, enough for any store, and a setting lets a machine widen it without a release. The log is immutable, so ids already filed cannot be rewritten.

Rejected: rewriting existing ids to the new length. Every graph entry, note and commit pointing at an `m-` id would dangle, and the log forbids rewrites. Rejected: a fixed length with no setting. Widening it would need a release. Rejected: no upper bound. A mistyped setting would mint ids nobody can type.

Accepted costs: one store holds ids of several lengths; the schemas accept any length from 4 to 16, so they no longer catch an id of the wrong length for that store, only one of a length nobody mints.

Acceptance:

- `entry_id_length` unset mints `m-` and 6 characters; 3 mints 6; 8 mints 8; 40 mints 16.
- A store holding a 4-character id serves `show`, `retire`, `supersede`, `confirm`, `revive`, `retitle`, `tag` and `retain` on it through the CLI and the MCP tools.
- A random byte at or above 252 is drawn again rather than folded into the alphabet.
- `README.md`, `agentic-helpers:agent-memory` (its `m-xxxx` mentions) and the plugin's `userConfig` describe the length and the setting.
- Each new guard is broken, its test watched failing, and the file restored byte-identically.
