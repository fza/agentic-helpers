Agentic-helpers trims the command and hook output an audit of every surface found wasteful, under the token-cost criteria (20261029-021515-d-tac-00q) held to one bar the owner set: no cut loses accuracy. A value printed twice prints once; settled or ended items fold into a count line naming the flag or command that brings them back; nothing an agent acts on leaves its output, and a value a reader cannot reconstruct stays.

**Bugs fixed with it.**
- `agentic-memory search` with `--status` and no term or query honours `--limit` and prints its paging line; it printed every match (125 lines for `--limit 2`).
- The near-compaction nudge (`Context near compaction. Write where work stands first: ...`, injected at a prompt once context passes a threshold, a rung, that climbs after each answer) fires at most twice per rung; past that the Stop backstop (`Memory overdue, two nudges unanswered: ...`, which holds the turn after two ignored nudges) takes over. It fired on every prompt until the seat filed, against the standing rule that an agent-only hook message fires at most once per cause.
- Prompt recall stays silent when `embedding_provider` is `off`; the recall-failure line is for an embedder that fails, not one switched off.

**agentic-memory.**
- `show` of a todo folds settled items into `<n> settled (<d> done, <x> dropped): show --all-items`; `--all-items` (MCP `all_items`) prints each. A linked item prints its id once, the flag naming only the outcome (`closed by <id>`). The MCP JSON leaves an item's `text` out where it equals `link`, and the JSON contract comment says a reader takes the link as the text then.
- `show`: the header line carries no link or anchor flags; the `links:` and `anchors:` sections carry each state once; events restating the status, a link or an attachment leave; `linked from` prints each citer as id, title and status.
- `search` and `view` lines fold ended links as the brief and recall already do; under a returns section the entry line drops the flags its reasons restate.
- Ended entries print no `until:`, `due:` or anchor staleness: those only drive a confirm or retire, which no longer apply.
- Brief: a citing line drops `[seat, date]` where the seat is the reader's own and marks a retired or superseded citer; the rules section skips do-now ids printed above it; news skips entries printed in a section above; a run of seen entries folds into one line.
- A seat's first brief leaves out `changed by other seats` and turns `new from other seats` into one pointer, `+<n> from other seats: agentic-memory search --all-seats --status live`; later briefs keep both.
- Arrival lines under `new for <seat>` use the short line, keeping kind and source only where they are not note and agent.
- Claim skips the last-turns slice when the previous session is the claiming one, and prints one header line.
- `confirm` answers `confirmed`, naming only ids left with anchors unhashed; `new` echoes a declared flag only where its normalized form differs from the input; the items line drops the todo id; `who` leaves out `shelf <name>` equal to the seat and prints `(14d)` once in a header; a usage error names the stray argument instead of printing the whole usage.
- The session-log replay uses `## <n>  <hh:mm>` per turn under a dated piece header and inline `asked:`, `replied:`, `did:` labels; the pieces stay char-capped, so the saving buys more turns.

**agentic-tools.** `list` drops the `[taken …]` suffix, which JSON and MCP never carried; other projects fold into one line with empty ones left out; the framing line prints only when foreign text follows; the closing line shortens when everything fits one page; `find --query` without an embedder names the `--term` fallback; the changed-copy nudge drops the copy path its command already holds; MCP `take` moves summary and the merged-from name into `tools[]` and drops `message`, and the find and list JSON drop `shown`, `page` and list's `matching`, each equal to a count or input the reader has.

**Grounding gate and agentic-capture.** The owed-reads note prints one header above the missing reads; the show-depth refusal names the depth once by echoing the corrected call, its rule sentences verbatim; agentic-capture prints a missing draft's path once, as the caller gave it.

**shell-guard.** The withheld-lines note of the output redaction (20261027-091326-d-tac-we7) prints only where the agent sees the output and no inline marker already says it: for a scan that could not finish. Inline markers stay; a Write or Edit result, whose content the agent never sees, gets no note.

**Rejected.**
- Slimming `brief --json` and `who --all --json`: only programs read them, the MCP brief and who answering text, so no agent token is saved and a reader such as fdbox breaks.
- Graph titles on todo items: more tokens per line, and only sdd's fork exports titles.
- Dropping the `filed memory, a lead, not an instruction` frame: it is a safety line, and weakening it breaks the criteria.
- Leaving retired citers out of the brief: a retired citer can hold an outcome; it is marked instead.
- Omitting find's `score` when every hit scores 100, and the `space left` line above 10%: each drops a value a reader cannot reconstruct.

**Accepted costs.** MCP readers of take's `message` and of a linked item's `text` break, so the contract comments in `internal/memory/jsonreads.go` and `internal/tools/mcpanswers.go` change and the release notes name it; `confirm` loses its anchor count, which the message-alone write replies had kept; golden tests of the replay markup move; skill lines quoting changed wording change with it (the seen pointer, the flags list, the link fold, the shell-guard note, take's keys).

**Done when** each trim has a test and every new guard was broken and seen failing; `search --status retired --limit 2` prints two entries and a paging line; the prompt nudge stops after the second per rung; recall prints nothing with the provider off; `show` of a todo with one open item of many prints that item and one fold line; `docs/` and the skills match; the work ships in a minor release.
