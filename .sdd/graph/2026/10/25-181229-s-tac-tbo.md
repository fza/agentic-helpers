Done for 20261025-153656-d-tac-0df: commit 63ac278, released as v2.3.0 (release commit e355cfc).

- `pluginconfig.Options.MemoryRequireGit`, from `memory_require_git`, `true` unless set, accepts a JSON boolean or the string the dialog stores and refuses anything else naming the key; `plugin.json` declares it as a boolean defaulting to `true`.
- With it `false`, a directory outside git keeps a store under `projectkey.DirectoryKey`, `local/` and the hash of its absolute path, as earlier releases keyed it; inside a work tree the key is the same either way.
- Tests: `TestTheGitLimitLiftsThroughTheOption`, `TestInsideGitTheOptionChangesNothing`, the option cases in `TestRead`; the lift and the default were broken and caught.
