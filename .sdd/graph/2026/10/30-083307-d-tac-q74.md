agentic-helpers' embedding options take sdd's set and names, and where agentic-helpers configures no embedder it falls back to sdd's, so one embedder setup serves both tools and memory and tool search get the query and document templates their model expects.

Why: agentic-helpers embeds raw text, while sdd wraps queries and documents in templates (`embedding.query_template`, `embedding.document_template`) that models such as embeddinggemma are trained on, so search ranks worse than it could. Its HTTP timeout is fixed at 30 seconds in code (`cmd/agentic-memory/main.go`), where sdd's `embedding.timeout` is set per machine. Configuring the same embedder twice invites drift.

**Keys.** `embedding_provider` (`openai` or `ollama`), `embedding_model`, `embedding_endpoint`, `embedding_dimensions` and `embedding_api_key_env` stay. New: `embedding_timeout`, a span as sdd spells one (default `2m`), bounding each embedding call of a command or MCP tool; the hooks that embed on the way (agentic-memory's per-prompt recall, agentic-tools' per-prompt offer) keep their own shorter deadline, which never exceeds it. `embedding_query_template` and `embedding_document_template`, each holding `{text}` where the text goes, as sdd's do; empty embeds the text as it is. A search query or a prompt is embedded through the query template, an entry chunk or a tool description through the document template.

**Fallback.** Where `embedding_provider` is empty in every layer, agentic-helpers takes sdd's whole embedding block, read once per process with one `sdd config get embedding` run in the checkout, so sdd's own layering (global, then the repository's) decides. Keys are never mixed between the two: an own provider means only own keys apply. No sdd on the PATH, or an sdd answering no embedding block, leaves semantic search off as an empty provider does today.

**Key.** The API key comes only from the variable `embedding_api_key_env` names, and is sent only to an endpoint set in agentic-helpers' own options. Under the sdd fallback no key is sent: sdd prints its keys masked, and sdd's config file is agent-writable, so sending agentic-helpers' key to an endpoint read from it would reopen what 20261029-145943-d-tac-gp7 closed. The fallback therefore serves keyless embedders, such as a local server; a hosted one is set in agentic-helpers' own options.

**Vector marker.** Vectors are kept per fingerprint, and each segment records its width and refuses rows of another (`internal/vectorseg`). The fingerprint today is the provider and model, plus the dimensions for `openai` only. It becomes provider, model, dimensions for both providers, and a hash of the two templates, so changing a template or a width starts a fresh vector folder and re-embeds once, rather than ranking new vectors against old ones. The endpoint stays out of it: moving a local server to another port would otherwise re-embed everything.

**Rejected.** Reading sdd's config files directly for its keys: it would copy sdd's layering and read secrets sdd chose to mask. Mixing keys per field between the two: a model from one provider could pair with another's endpoint. Keeping the timeout fixed: a slow local embedder times out where sdd's setting would wait.

**Accepted costs.** One `sdd config get` per process while the fallback applies. Every store's vectors re-embed once on the release, since the fingerprint changes. A hosted embedder still needs its key variable set in agentic-helpers.

**Acceptance.**
- With no own provider and sdd configured, memory and tool search embed through sdd's provider, model, endpoint, timeout and templates, and send no key.
- With an own provider, nothing of sdd's applies.
- A query embeds as the query template with `{text}` replaced; an entry chunk and a tool description as the document template.
- A template or dimension change gives a new fingerprint and a fresh vector folder; an endpoint change does not.
- No sdd, or no embedding block, leaves semantic search off without an error beyond today's.
- `embedding_timeout` bounds a command's embedding call; the hardcoded 30 seconds is gone.
- README `Options`, `docs/memory/` and `docs/tools/` describe the keys and the fallback.
