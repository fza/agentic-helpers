`agentic-memory view --layout` reads the store through sdd's layout language, one filter set serves view, `search`, the brief and MCP, and reads no longer scale their subprocesses with the store, in agentic-helpers commits 9527cf4 to 1b1055d and f59334a, not yet released, completing 20261027-004736-d-tac-abm.

Measured on a 70-entry store, each entry linking a graph entry: one `show --no-heat` ran 77 subprocesses in about 500 ms before; it runs 2 in about 50 ms after (one common-dir lookup, one combined `git rev-parse`).

Each criterion with its test in `internal/memory/` and `internal/layout/`:

1. Every word filters as stated, refusals name token and position over CLI and MCP: TestEveryViewWordFiltersAsStated, TestViewRendersEachTerminator, TestViewJSONHasOneObjectPerSection, TestViewRefusesNamingTokenPositionAndNearestWord, and `internal/layout/layout_test.go`.
2. `inbox:unread` and the arrival notice name the same entries, a shelf mate's among them; a view leaves the seen mark and `heat.json` unchanged: TestInboxAgreesWithTheArrivalNotice, TestAViewWarmsNothingAndMovesNoMark.
3. `returns` reports each reason and `unchecked` for a cold graph cache or an unreadable file: TestReturnsReportsEachReason, TestReturnsShowsWhatCannotBeCheckedAsUnchecked.
4. Golden files pinned `brief` text and `search --json` before the filter set replaced their code, and both stay byte-identical: TestReadsMatchTheirGoldenText.
5. Two spawns for two links and for twenty-four: TestShowSpawnsTheSameWhateverTheLinkCount; a second read of an unchanged store reads no segment: TestASecondReadOfAnUnchangedStoreReadsNoSegment.
6. The docs and agentic-helpers:agent-memory name the language, the vocabulary and the refusals.

Deviations: a parse error names what was expected at the position, and an unknown word or value names the nearest one; a new word `mine` (the calling seat's shelf and what it receives) and MCP key `explain`; `search --topic` and `brief --topic` match by component prefix, as `topic(L)` does; `returns` reads only the cached graph statuses, never running `sdd export`; the commit stamp is the full SHA cut to eight characters, so a combined `git rev-parse` can answer.
