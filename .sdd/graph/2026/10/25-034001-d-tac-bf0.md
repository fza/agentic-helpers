It builds on the agentic-memory directive (20261025-014326-d-tac-mvn) so unattended sweeps can read repeatedly without pinning entries atop every seat''s brief or racing unlocked warms on heat.json.'

`agentic-memory search` and `agentic-memory show` take `--no-heat`; their MCP tools take `"no_heat": true`. A read carrying it answers exactly as without it and leaves `heat.json` untouched: no `show` heat (0.5), no heat for a search's top three hits (0.25 each), no write of the heat file at all. Without it, nothing changes. No other command takes it, and prompt recall in `UserPromptSubmit` keeps warming its hits.

Why: heat orders each seat's brief, and an unattended caller reading the same entries on every pass (fdbox's scratch sweeps run `search`, then `show`, on every entry naming a `.tmp/` path, several times per pass) keeps those entries at the top of every seat's brief as if a person kept reaching for them. Each warm is also a read-modify-write of `heat.json` without a lock, so a sweep's warms can overwrite a seat's own.

Rejected: seatless reads warming nothing. Covers a plain shell without a flag, but does nothing for a sweep running inside a seated session, and whether a caller holds a seat says nothing about whether a person is reading. Rejected: both rules together. Two rules to document and test for one need the flag already meets. Rejected: an `AGENTIC_MEMORY_NO_HEAT` environment switch. Invisible in the command, and inherited by every child process, so a variable set once can silently stop heat for whole sessions.

Accepted costs: every unattended caller has to pass the flag; warms that do run still race on `heat.json` without a lock, costing ranking, never memory.

Acceptance:

- `search --no-heat` and `show --no-heat` print what they print without it, and `heat.json` is byte-identical before and after; without the flag both still warm as before.
- The MCP `search` and `show` tools take `no_heat` with the same effect, and their schemas list it.
- `agentic-memory help`, `README.md` and `agentic-helpers:agent-memory` name the flag.
- Each new guard is broken, its test watched failing, and the file restored byte-identically.
