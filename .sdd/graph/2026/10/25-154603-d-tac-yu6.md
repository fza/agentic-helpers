title: Search paging via --skip
summary: agentic-memory search and the memory MCP search gain a --skip/skip offset that drops the first N results before --limit cuts the page. `agentic-memory search` takes `--skip N`, and the `memory` MCP tool `search` the key `skip`, a non-negative integer: the first N results of the ranking or listing are dropped before `--limit` (10 unless set) cuts the page. Where results remain past the page, its last line names the next page's flag:

- `14 more: --skip 10` where the remainder is exact: a search by `--term` alone and a `--status` listing.
- `more: --skip 10` where a `--query` takes part, since every candidate carries a score and the remainder is the rest of the store.

No line follows the last page. Each ranking arm keeps `skip + limit` candidates before fusion, so page two of a hybrid search is the fused ranking's second slice, not a fusion of each arm's second slice. A page with `--skip` above 0 warms nothing: the top three a search warms are the top of the ranking, which only the first page shows. The name follows sdd's `skip(N)` view primitive.

Why: `--limit` alone cuts a long result and hides that it did, and raising it to see the rest repeats every earlier hit in the context. An offset pages a ranked search, which has no stable cursor, and a time-ordered listing alike.

Rejected: `--page N` (a word with no precedent in sdd, and a changed `--limit` between pages moves where a page starts without saying so); a footer telling the agent to raise `--limit` (every next page repeats every earlier one); a cursor such as `--after <id>` (a ranking by meaning or fused rank has no position an id can mark); an interactive pager (an agent reads output whole and never drives `less`).

Accepted costs: an entry filed, ended or warmed between two pages shifts the list, so one result may repeat or be passed over; a deep page of a hybrid search costs as much ranking as all the pages before it.

Acceptance criteria:

1. `--skip` and the MCP key `skip` are accepted on every search; a negative value is refused naming the flag.
2. Over a store of 25 matching entries, `--limit 10` pages with `--skip 0`, `10` and `20` return disjoint results covering all 25 in order, with footers `15 more: --skip 10`, `5 more: --skip 20` and none.
3. A hybrid search's second page equals results 11 to 20 of the same search run with `--limit 20`.
4. A search with `--query` ends a non-final page with `more: --skip <n>`.
5. A page with `--skip` above 0 changes no heat.
6. `README.md` and `agentic-helpers:agent-memory` name `--skip` and the footer.
