agentic-memory builds no filing-time check against the graph ("the graph may already hold this") now. The case it was meant for, an owner decision left in memory after its capture, is covered by `--until captured` (20261026-215617-d-tac-45q), and nothing yet measures how often a note restates a captured decision. The forbidden-content warning (20261026-221254-d-tac-d5y) is the filing-time check that is built.

Why settled: the deferral is the whole of the decision. Nothing follows until notes restating captured decisions show up in practice; a new directive then builds the check under the guards below.

How it would be built, since sdd as it ships offers no shortcut: sdd's search embeds its phrase as a query on every call, takes no vector, prints no score and keeps no query vectors, so a check that embeds the new entry once needs memory to index the graph itself, title and summary from `sdd export`, embedded with memory's own embedder. It takes three guards:

- Index only while memory's embedder fingerprint equals sdd's, so graph text never goes to a provider sdd does not use.
- Cache vectors only, keyed by entry id and summary hash, and print ids and summaries from the current export: any sandboxed job can write the memory store (20261025-185324-s-tac-k4o), so a planted vector can only skew the ranking of an advisory warning, and `sdd summarize` replacing a summary invalidates its vector.
- Use the relative floor memory's similar-entry check already applies (mean plus two deviations), so no absolute score needs tuning.

Rejected alternatives:

- A change to sdd taking or emitting a query vector: memory works with sdd as it ships.
- Calling `sdd search --query` per filing: embeds the same text a second time and returns no score to apply a floor to.
- Reading sdd's index files: a private format sdd may change in any release.
- Building the check now with the guards: a second index of the graph with its fill and invalidation code, and a batch embed of every entry on first use, for a case no measurement shows.

Accepted costs:

- A note restating a captured decision lands without a warning; the only guard is agentic-helpers:agent-memory's routing table, which sends a decision to the graph and has memory point at its id rather than hold a second copy.
