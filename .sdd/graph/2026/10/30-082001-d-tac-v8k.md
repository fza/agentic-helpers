Every file agentic-helpers creates, opens for writing, appends to, renames or makes a folder for, under the data home, the cache home or inside a checkout, goes through one shared package, `internal/safefs`, which walks the path folder by folder and never follows a link below its root. It closes the planted-link gap (20261030-081445-s-tac-xjr): a process allowed to write part of the home, or a repository's committed files, can no longer turn the owner's processes into writers elsewhere. The homes stay bookkeeping for what a writer stores (20261028-204914-d-tac-6xf); this only stops the owner's writes from leaving them.

**Mechanism.** The tool library's descriptor walk (`internal/tools/safefs.go`, `internal/tools/safewrite.go`) moves into `internal/safefs`, and the tool library uses it from there. A root is opened once; the root and every folder above it are the owner's and may be links. Below the root, each component is checked with `lstat`, refused as a link, opened relative to its parent's descriptor through `os.Root`, and held to the checked folder, so a link swapped in between is caught. Files are written three ways: a new file is created exclusively (`O_EXCL` never opens an existing name, a link included); a replacement is written under a fresh random name and renamed over the old one, so a link at the old name is replaced, never written through; an append or lock opens the file, then refuses it unless it is a regular file, the one its folder names, with no second hard link, before a byte is written. A file agentic-helpers writes is refused wherever it carries a second hard link.

**Roots.** `$XDG_DATA_HOME/agentic-helpers` (or `AGENTIC_HELPERS_HOME`), `$XDG_CACHE_HOME/agentic-helpers`, the checkout's top folder, and the git common dir. Inside a checkout that covers `.tmp/` and its scratch folders, `.gitignore` edits, `<git common dir>/agentic-store`, and `.sdd/tmp/capture.lock`. The one-time migration that moves old data from `~/.claude` into the home (`internal/migration`) reads those old trees and writes into the home through it too. `internal/atomicfile`, the memory log, seat and shelf registries and locks, attachments, caches, bindings, vector segments, identity files, the space ledger and the slots file all write through it.

**Wording.** The refusals keep the tool library's error texts: `<path> is a link`, `<path> changed while it was opened`, `<path> is no regular file`, `<path> has a second name, a hard link; ...`. The docs and skills quoting them name the wider reach in the same change.

**Rejected.** A no-follow flag on the last path part only: a folder renamed in under a name the owner uses later can hold its link one level down, which the flag never sees. Leaving it to the caller's sandbox: every later sandboxed caller would need to repeat the rule, and agentic-helpers would keep writing through links. Covering the homes alone: a cloned repository committing a `.tmp` link would still redirect scratch and capture writes.

**Accepted costs.** One change touching roughly every writer package, each with its own planted-link test. A planted link makes a write fail, so a sandboxed job can break its own store's writes; it could already do so by writing garbage. One open per folder level on every write. That migration, already delicate, gains the walk.

**Acceptance.**
- No package outside `internal/safefs` calls `os.OpenFile`, `os.Create`, `os.WriteFile`, `os.Mkdir`, `os.MkdirAll` or `os.Rename` on a path under a root named above.
- For every writer, a test plants a symlink at the file, a symlink at a folder one level up, and a hard link at the file, and sees the write refused with nothing written outside the root.
- A folder holding a link, renamed into `stores/<id>/memory/` under a name the store does not yet have, is refused on the owner's next write there.
- A link swapped in between a component's check and its open is refused.
- A checkout whose committed `.tmp` is a link gets no scratch write through it.
- The tool library passes its existing safe-store tests against `internal/safefs`.
- A root that is itself a link, such as a symlinked `~/.local/share`, keeps working.
