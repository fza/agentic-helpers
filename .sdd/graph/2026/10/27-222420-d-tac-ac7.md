agentic-memory's Stop hook holds the turn's end once when a seated session shipped work since its seat's last state write, asking for a state write before the turn ends. A seated session is one whose claude process holds a seat through its claim file, as the claim force flag removal (20261025-164209-d-tac-qj7) describes; a seatless session holds none.

Why: today every state request is tied to context fill (the compaction nudge, its Stop backstop) or to the replay outgrowing its pieces (20261025-192326-d-tac-303). A session that ships commits and releases without nearing compaction is never asked, and the seat's state slot (20261026-215042-d-tac-g5a) stays empty or describes work long finished.

Shipped work, measured since the seat's last state write in this session, or since its claim where none:

- HEAD moved: the commit the state row stamps (or the claim's) differs from HEAD now, one `git rev-parse` at Stop;
- a graph entry was captured: the graph gained an entry, as the capture notice already reads it;
- file writes: the memory tool hook counts Edit, Write and NotebookEdit calls, and the count reaches the plugin option `state_stale_after_writes`, default 5.

The hold: exit 2 at Stop with one line, `Work shipped since your last state write. Write where work stands: agentic-memory state < body. Then end the turn without commentary.` It fires once per quiet period: a `held` mark on the session's ladder file, cleared only by the seat's next state write, so an ignored hold never repeats: the owner's standing rule is that hidden messages to the agent stay as scarce as possible. A hook-written draft state does not count as a write. A seatless session, a chat-only session and a session whose state is newer than its work are never held. Among Stop's checks it runs after the hold for owed do-now rules and before the compaction backstop, and leaves the nudge count alone.

Rejected: blocking `git commit` or a release command until state is written, which taxes every commit, the owner's own included; a hold on every Stop with shipped work, which repeats; a fixed threshold, which the owner cannot make rarer.

Accepted costs: one extra agent turn per shipping period; a commit made by hand outside the session moves HEAD and can trigger one hold.

Acceptance criteria:

1. Each trigger (moved HEAD, a new graph entry, writes reaching the threshold) holds Stop once with the line above, checked by a test per trigger.
2. A second Stop without a state write passes; a state write clears the mark and the next shipped work holds again.
3. `state_stale_after_writes` sets the threshold, default 5, read like the other plugin options.
4. Seatless and chat-only sessions are never held.
5. Each guard is broken once and its test watched failing; agentic-helpers:agent-memory quotes the line and `docs/memory/` describes the hold and the option, in the same change.
