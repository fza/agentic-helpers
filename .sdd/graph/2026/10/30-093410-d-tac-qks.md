A seat claim creates `.tmp/` where a git checkout lacks it and scratch is on, so a seated session always gets its `.tmp/claude/<seat>/` folder without anyone creating `.tmp/` by hand.

Why: every agentic-helpers piece stays silent in a project without its directory (`source/AGENTS.md`), and agentic-scratch's directory is `.tmp/`. The seat folders of 20261030-082426-d-tac-h68 therefore did nothing in a fresh project until a person created `.tmp/`, and agents fell back to their own choice of place. Claiming a seat is already an explicit opt-in to agentic-helpers for that project, so the claim may create the folder its scratch needs.

**Rule.** `agentic-memory claim` (and the MCP claim) in a git checkout, with `scratch_enabled` on, creates `.tmp/` in the main checkout where it is missing, then the seat's folder as h68 decides. Since `.tmp/` is now there before agentic-scratch's next session start, the claim itself runs the global git excludes step of 20261026-213516-d-tac-vrp for `.tmp/`, printing its line once where it adds the pattern. A directory outside git, a claim with scratch off, and a session holding no seat create nothing; agentic-scratch's own hooks keep the opt-in rule and never create `.tmp/`.

**Rejected.** Keeping `.tmp/` opt-in: seat folders, and agentic-scratch's removal of throwaway folders, do nothing in a fresh project. Creating `.tmp/` at every session start in any git checkout: every repository opened gets one, also where agentic-helpers is never used.

**Accepted costs.** Every project where a seat is claimed gains a `.tmp/` folder; the silent-without-its-folder rule has this one exception, at an explicit claim.

**Acceptance.**
- A claim in a git checkout without `.tmp/` creates `.tmp/claude/<seat>/` with its marker and prints the scratch line, and adds `.tmp/` to git's global excludes where git does not ignore it.
- With scratch off, outside git, or with no seat claimed, no `.tmp/` is created.
- `docs/scratch/usage.md`, `docs/memory/usage.md` and the agent-scratch skill say so.
