Agents writing agentic-memory entries state the outcome (the finding, the decision, the step owed) and never play back the user's prompt or answer. A rule keeps the user's instruction alone, verbatim, with nothing of the prompt around it. It adds to the terse writing style of 20261029-021652-d-tac-xzt, which cuts filler from what agents write, a rule on what they write at all. Every other kind quotes nothing the user said and narrates no "owner chose", "owner asked" or "user said": `--from user` already records whose an entry is.

Why: a count of the store's 189 entries found up to 7% of all entry text inside quotation marks, an upper bound since quoted code and errors count too. Rules were 32% quotes, and 34 of the 64 user-sourced todos and notes quoted the prompt. 52 entries carried a line narrating what the owner chose, asked or said. Filing pays for that text in output tokens, about five times the cost of input. Every `show` of the entry pays for it again in input. The outcome is what a later session acts on; the playback adds nothing it acts on, so by the token-cost criteria of 20261029-021515-d-tac-00q it goes. A rule keeps the quote because it never decays and steers every later session, and a paraphrase can drift from what the user meant.

**Where it lands.** The `agentic-helpers:agent-memory` skill: the rule row of the kinds table says the instruction alone, verbatim, and a writing rule says outcome, never the prompt. `docs/memory/usage.md` states the same under kinds and sources. The `new` MCP description of `body` names it.

**Rejected.**
- A check at filing that flags a body repeating the last prompt: it reads the transcript on every filing, adds a reply line, and arrives after the output tokens are spent.
- Paraphrasing rules too: saves about 1.5k characters across the whole store, at the drift risk named above.

**Accepted costs.** Nothing enforces the rule. An agent ignoring the skill still files a playback, and only a reader of the store notices.

**Acceptance.**
1. The skill's rule row and a writing rule state the above.
2. `docs/memory/usage.md` and the `new` MCP `body` description say it.
3. Entries filed by sessions running the released skill carry no prompt playback, checked by the same count over entries filed after the release.
