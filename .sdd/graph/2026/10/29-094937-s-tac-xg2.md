`agentic-capture` now removes a captured draft, switched by the `capture_remove_draft` option, and never deletes through a symlink, a file git tracks, or on an unclear git answer, completing the directive (20261029-023740-d-tac-yl8). Commits 284179c, 86ee9e6 and cfee655 carry it with tests for every acceptance case (success, failure after the write, tracked, outside the work tree, option off) and with the skill and docs changes, not yet released. Live on the installed binary in a throwaway graph, capturing an untracked draft printed `draft removed: <path>` and the file was gone, while capturing a committed draft printed `draft kept: <path> is tracked by git` and the file stayed.
