agentic-memory leaves Claude Code's compaction in place: it neither blocks compaction nor replays turns after a `/clear`. A `/clear` keeps bringing back the seat's brief without the last turns; compaction followed by the turn replay stays the path that carries a session past a full context.

**Why.** Claude Code gives a plugin no way to run `/clear` or replace the compaction summary (code.claude.com/docs/en/hooks, "PreCompact", "PostCompact"). A `PreCompact` hook can only block: a proactive auto-compaction is skipped and the conversation continues uncompacted, and a compaction triggered by a context-limit error fails the running request. Clear-and-replay therefore always needs the user to type `/clear`, and the compaction it would replace already ends with the replay.

**Rejected.**
- Replaying the last turns on `/clear` and naming that path in the near-compaction nudge: no session fails, but it adds a second recovery path beside compaction while the user still types `/clear`.
- An option blocking auto-compaction and asking the user to `/clear`: every turn past the compaction window grows pricier, and at the model's limit the running request fails with `Context limit reached`, stopping an unattended run.

**Accepted costs.** A `/clear` returns without the last turns; a user wanting them compacts instead.
