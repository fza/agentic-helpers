Everything agents write into the agentic-memory store and the agentic-tools library is terse by default, and sdd graph entries stay plain prose. One option, `writing_style`, takes `terse` or `plain` (default `terse`) and resolves through the `config.yaml` layering of 20261028-212647-d-tac-cld, which already lists it among the keys an agent may override.

**What terse covers.** Memory entry titles (the 3 to 10 word rule stays), bodies and the state slot; the tool library's summary, usage and version notes. Titles follow the same setting, because only agents read them.

**What it means.** Drop articles, filler and hedging; fragments are fine; code, paths, ids, quotes and domain terms stay exact. The agent-memory and agent-tools skills state these rules in their own words. The style matches the caveman plugin's "full" mode (a Claude Code plugin that makes the agent write compressed text), yet needs no such plugin installed, and the plugin's own text is not copied.

**Surfaces.** The brief header names the style beside the entry language of 20261025-151706-d-tac-f7p: `entries in <lang>, terse`. The skills `agentic-helpers:agent-memory` and `agentic-helpers:agent-tools` carry the rules; the MCP descriptions of memory `new` and `state` and tools `add` and `update`, and each command's `--help`, name the style. The library of 20261025-185701-d-tac-e9x is covered for its summary, usage and version notes.

**Graph stays plain.** Entries captured through sdd's engine or `agentic-capture` are plain prose: people read the graph, and sdd's writing review tests whether an entry reads on its own.

Why: agents are the only readers of memory and of the tool library, so articles and filler cost tokens on every brief, recall and listing and inform nobody.

Rejected: always terse with no option (no way back for an owner who wants plain text); plain by default (keeps the cost where nobody gains); plain titles (no human reader to serve); graph drafts terse too (clashes with sdd's writing guide, the pre-flight and `draft_lint`).

Accepted costs: one more option; a human reading a memory store or tool notes reads fragments.

Acceptance:
- `writing_style` resolves through the `config.yaml` layers, default `terse`; an unknown value is refused as the reader refuses any invalid value.
- The brief header reads `entries in <lang>, terse` under `terse` and names `plain` under `plain`.
- Both skills state the terse rules; the MCP descriptions and `--help` of the four writing commands name the style.
- The agent-capture skill and capture docs keep graph entries in plain prose.
