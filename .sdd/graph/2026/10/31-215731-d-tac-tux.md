Inside a shell script shell-guard reads (20261031-211859-d-tac-59g), a removal is judged by its targets alone, and nothing found in the script is refused: every verdict that would refuse a typed command asks instead. A typed command keeps every rule it has.

**What changes inside a script.**
- `rm`, `rmdir`, `unlink` and `git rm` with targets in the project pass, whatever else the script runs; targets outside the project, unresolvable or with no project ask, with the reason prefixed `in the script <name>: `.
- The rule that a removal runs alone in its Bash call does not apply: it exists to keep an agent's typed removal readable, and a script holds many commands by nature.
- A removal target holding an expansion, code handed to another runner that names a removal, a command name that is not fixed text, and `mktemp` ask instead of being refused.

**Why.** Judged exactly like a typed command, `./configure`, `./gradlew` and most build scripts, which clean up inside the project beside other commands, are refused on every run for every user; a variable-named command (gradlew's `exec "$JAVACMD"`) asks. The guard's purpose inside a script is to stop write-then-run from removing files outside the project unseen, and an ask keeps that: the user sees the call before it runs.

**Rejected.** Judging a script exactly as a typed command: blocks ordinary build scripts for every user. Keeping every rule but turning each refusal into an ask: almost every real build script still prompts, and in Claude Code's auto mode shell-guard denies an ask nobody answers after a countdown (`docs/shell-guard/usage.md`).

**Accepted costs.** A script removing `$DIR` or running a variable-named command still asks. A script written to slip a removal past the hook gets a prompt where the same typed command would be refused outright.

**Acceptance.**
- A script holding `ls` and `rm -rf build` passes.
- A script holding `rm -rf ~/x` asks `in the script <name>: outside project: ~/x`.
- A script holding `rm -rf $DIR` asks; no verdict from a script's text is a refusal.
- Typed commands get the same verdicts as before.
- `docs/shell-guard/usage.md`, `docs/shell-guard/architecture.md` and the agent-shell-guard skill state the script rules.
