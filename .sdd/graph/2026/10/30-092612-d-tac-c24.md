agentic-helpers takes sdd's embedding endpoint only from sdd's `global` or `default` layer, and refuses sdd's whole embedder when `sdd config get embedding` reports the endpoint from any other layer, so no file a cloned repository carries can choose where memory entries and prompts are sent.

It supersedes 20261030-092327-d-tac-cz3, which refused only the `project` layer (the committed `.sdd/config.yaml`) and trusted the `local` layer as uncommitted. That trust does not hold: sdd gitignores `.sdd/config.local.yaml` by convention only, and a repository can commit one just as well. A deny-list also lets through any layer a later sdd adds, such as a split layout's graph repository. An allow-list of the layers living outside every repository closes both.

Why at all: the sdd fallback of 20261030-083307-d-tac-q74 takes sdd's whole embedding block, and sdd layers the repository's files over the user's global configuration. Under `auto` with no own provider, the default on a fresh machine, a clone setting `embedding.endpoint` would receive every entry agentic-memory embeds and every prompt it recalls against. Sending no API key, as q74 rules, does not stop that: the text itself leaks. 20261029-145943-d-tac-gp7 kept the endpoint out of agent-writable files for the same reason.

**Rule.** `embed.Settle` reads the layer printed last on each line, in parentheses; sdd escapes a newline inside a value as `\n`, so a value cannot forge a line, and a value holding a parenthesis still leaves the last one as the layer. An endpoint from a layer other than `global` or `default` refuses the block with `embed.ErrRepositoryEndpoint`, naming the layer. A block printing any key twice, which sdd never does, gives no embedder. No endpoint at all leaves the provider's own default. Provider, model and templates from any layer still apply, since they send nothing anywhere new. Under `auto` and `sdd` alike (20261030-084308-d-tac-pz4) the session start says: `agentic-helpers: sdd's embedding endpoint is set in this repository's .sdd/ (layer <layer>), which a clone can bring along; search by meaning stays off until `sdd config set` sets it in sdd's global layer, or embedding_provider and embedding_endpoint set one here`.

**Rejected.** Refusing only the `project` layer, as cz3 did: a committed `.sdd/config.local.yaml` and any future layer pass. Trusting `local` where git does not track the file: one more git call per process, and an untracked file a clone's setup script writes passes too. Reading sdd's configuration as JSON: `sdd config get` offers no JSON form. Making `own` the default source: every machine would lose semantic search until configured, as pz4 rejected. Accepting only a loopback endpoint from a repository layer: still aims requests at local services, with a rule to test per address form.

**Accepted costs.** An endpoint set with `sdd config set --local` no longer reaches agentic-helpers; it must be set globally, or in agentic-helpers' own options. A team committing its endpoint gets no search by meaning from the fallback until each member sets it globally. Under `auto`, the session-start check runs `sdd config get embedding` once wherever no own provider is set.

**Acceptance.**
- An endpoint from `global` or `default` applies; from `project`, `local` or any other layer the block yields no embedder and `ErrRepositoryEndpoint`.
- A block printing a key twice yields no embedder; a value holding a parenthesised layer mark still takes the last one as its layer.
- The session-start check prints the line above under `auto` without an own provider and under `sdd`, and nothing under `own`.
- README `Options` states the rule.
