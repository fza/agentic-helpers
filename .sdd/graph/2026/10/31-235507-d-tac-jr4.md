The subagent hook replaces only the first marker line (`agentic-helpers: <level>`) of an Agent prompt with the subagent's block and keeps every later marker line as plain text, so a spawner can hand a level on for a nested Agent call. Today `rewritePrompt` in `source/hooks/internal/memory/subagents.go` drops every marker line it finds, so a prompt saying "spawn a reviewer with" followed by `agentic-helpers: rules` on its own line reaches the child without that line; the done 20261031-214728-s-tac-msb names this as a cost of the ladder decided in 20261031-202547-d-tac-xmy.

**Why it grants nothing.** The level a subagent gets is still capped at its spawner's own, so a kept line can never raise a nested child above the child spawning it. Lines in the shape of a level line (`agentic-helpers level: ...`) are still stripped, so only the hook names the level the subagent's hooks read back.

**Rejected.** Teaching spawners to quote a nested marker inline in backticks, with no code change: the child must strip the backticks before its own spawn, and a child copying them verbatim spawns its reviewer at `none` with no notice of the miss. Keeping today's rewrite: nested marker instructions keep arriving broken.

**Accepted cost.** A prompt carrying two marker lines meant for the same child shows the second to the child as text; only the first sets the level.

**Acceptance.**
- A prompt holding `agentic-helpers: silent` and later `agentic-helpers: rules` gives the child level `silent` and a prompt still holding the `agentic-helpers: rules` line.
- A child at `silent` copying `agentic-helpers: full` into its own Agent call spawns at `silent`.
- A line `agentic-helpers level: full` in a spawner's prompt is still stripped.
- `docs/memory/usage.md` (`## Subagents`) and the agent-memory skill's `subagents.md` say how to pass a level on.
