The limit keeping agentic-memory inside a git work tree is switchable through the plugin option `memory_require_git`: a boolean, `true` by default, declared in `plugin/.claude-plugin/plugin.json` `userConfig` with the title "Memory only inside git" and read from `pluginConfigs` like every other option. Set to `false`, a session outside a work tree claims, files and recalls as it does inside one, its store keyed by `projectkey.DirectoryKey`: `local/` and the first 12 hex characters of the SHA-256 of the absolute working directory, the key earlier releases gave such a directory, so a store they left there is found again. Inside a work tree the option changes nothing. `projectkey.Key` keeps returning `ErrNoRepository` outside git; only agentic-memory falls back to the directory key, and only with the option `false`.

Why: some work happens outside any repository (a notes folder, a scratch area kept on purpose), and the owner of such a machine is the one to say memory is worth having there, without the default changing for everyone else.

Rejected: `memory_outside_git` with `false` by default (names what is gained instead of the limit, so lifting the limit means switching something on); a per-project switch (Claude Code reads plugin options only from user and managed settings, never from a project's `.claude/settings.json`, and a file inside a directory outside git would be a new lookup with nothing to anchor it); the hash of the directory as before but under a new prefix (stores already keyed on it would be lost).

Accepted costs: the option applies machine-wide, so it lifts the limit for every directory or for none; a store outside git keeps the costs the limit was set against (reached only from that exact path, no branch or commit stamps); the grounding gate's `exempt_seats` lookup stays on `projectkey.Key` and finds no seat outside git whatever the option says.

Acceptance criteria:

1. `pluginconfig.Options` carries `MemoryRequireGit`, read from `memory_require_git`, `true` when the key is absent; a test reads `false` from a settings file and refuses a non-boolean value naming the key.
2. With `memory_require_git` `false`, a functional test in a `t.TempDir()` outside git claims a seat, files an entry and finds it, with the store under `local/<sha12 of the directory>`.
3. With the option absent, the refusal and silence of 20261025-153034-d-tac-e7l hold, under the same test.
4. Inside a work tree, the key is the same with the option `true` or `false`.
5. `plugin.json` declares `memory_require_git` as a boolean with default `true`; `claude plugin validate .` passes.
6. `README.md` and `agentic-helpers:agent-memory` name the option and its machine-wide scope.
