Every tool of the plugin's `memory` and `tools` MCP servers answers one JSON object, in agentic-helpers commit eaf6c96, not yet released, completing the JSON answers directive (20261027-180531-d-tac-04v).

- `internal/mcpserver`: a `Result` carrying `Structured` goes out as `structuredContent` and, serialized, as the text block; `Refusal` answers `{"error": <text>}` with `isError`; `Messaged` puts `message` beside a fields struct's keys. Each tool's `outputSchema` comes from `SchemaOf`, which derives JSON Schema by reflection from the Go type the answer is built from, following `encoding/json` (a field without `omitempty` or `omitzero` is required, nil slices, maps and pointers are nullable, an outer field shadows an embedded one, objects stay open), so schema and answer cannot drift. An answer that fails to encode becomes a refusal saying so.
- Memory: `show`, `search`, `brief`, `view`, `who`, `topics` and `holder` answer their `--json` object; `view` with `explain` answers `{"message"}`; every other tool answers `message` plus typed fields (`internal/memory/mcpanswers.go`).
- Tools: `find` and `list` answer their listing; `take`, `add`, `update` (with `forked_from` for a fork), `merge`, `trust` and `reindex` answer `message` plus fields (`internal/tools/mcpanswers.go`); refusals keep the `refused: ` prefix inside `error`.
- The `json` key stays in the schemas, described as having no effect.

Beyond the directive: `brief --json` (and the MCP `brief`) now honours `--kind` and `--topic`, which the JSON path ignored before, and refuses an unknown kind first. `follow` and `unfollow` name the shelf under `shelf`.

Criteria: `TestEveryToolAnswersItsOutputSchema` in both packages calls every tool once and fails if a listed tool is left out; the memory test harness checks every MCP answer any test draws, refusals included, against its tool's listed schema or the refusal shape. `message` equals the CLI text is tested for `state`, and holds for every tool by construction, the message being the command's own text. `json: true` answering as a call without it is tested for memory `topics` and tools `list`. The skills `agentic-helpers:agent-memory` and `agentic-helpers:agent-tools` and `docs/memory/*`, `docs/tools/*` describe the answers. Every new guard was broken and its test watched fail.
