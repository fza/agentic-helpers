Done for 20261025-223045-d-tac-p2j: commit 58d4ddf, released as v2.8.0 (release commit bee16ef).

- `lifetime durable|temporary|<span>`, `claim --lifetime` and the option `temporary_seat_lifetime` (`1d` unless set, a note where it holds no span) set a lifetime; a `release` or a SessionEnd with any reason but `clear` or `resume` closes the seat onto `<id>.last.json` with `closed`; a holder gone without SessionEnd closes at its transcript's last write. The purge rewrites the log through `memorylog.Log.Rewrite`, keeps entries filed `--for` another shelf (their filer shown `<name> (expired)`, editable by the shelves they name), and frees every name. Retention `0` purges inside the closing `release` or SessionEnd.
- Deviation: the lifetime, the clock and the purge belong to the shelf, as 20261025-232110-d-tac-1oo refines.
- Deviation: SessionStart runs the purge over every store before it checks for its own project's store, so a session start in a project without memory still reads the machine's stores; a session outside git runs no hook and purges nothing.
- Tests: `lifetime_test.go`, `TestARewritePassesTheTailThroughThePolicy`. Every guard was broken and caught.
- Docs: `docs/memory/usage.md`, `docs/memory/architecture.md`, `agentic-helpers:agent-memory` in the same commit.
