agentic-memory's Stop hook now holds a seated session's turn end once for a state write when it shipped work since its seat's last one, closing 20261027-222420-d-tac-ac7. Commit 2be049a, not yet released.

- Shipped work: HEAD off the commit the last state write stamps, or off HEAD at the session's first tool call where it wrote none; a graph entry the capture notice saw added; or Edit, Write and NotebookEdit calls reaching the plugin option `state_stale_after_writes`, default 5, never under 1.
- The measure and the `held` mark live on the session's ladder file; a state write newer than the one seen clears both, so an ignored hold never repeats. It runs after the do-now hold and before the compaction backstop and leaves the nudge count alone. A compaction drops the ladder with the window, so the measure starts afresh then.
- Tests in `internal/memory/shipped_test.go` cover each trigger, the single hold, the clearing state write, the stamped commit as base, a commit before the first Stop, the option, and chat-only and seatless sessions; a `TestRead` case covers the option and its floor. Every guard was broken and its test watched failing, files restored byte-identically.
- Proven on binaries built from the commit, against a throwaway home and repository: a quiet Stop passed; a real commit held Stop with the line and the next Stop passed; after a state write four edits passed and a fifth file write held; after another state write a new graph entry file held.
- `docs/memory/usage.md`, `docs/memory/architecture.md`, `README.md` and agentic-helpers:agent-memory describe the hold and quote its line; the option is declared in `plugin/.claude-plugin/plugin.json`.
- The directive's exclusion of a hook-written draft state from counting as a write lands with the draft itself (20261027-222635-d-tac-fki), since no draft exists yet.
