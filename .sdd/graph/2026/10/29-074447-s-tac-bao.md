The agentic-memory inferred end "every link ended" no longer counts a memory target the entry itself superseded and never infers a todo's end from its links to memory entries, in agentic-helpers commit 02cc0de on main, not yet released, completing 20261029-022918-d-tac-bon.

Each acceptance case is a row of the table-driven TestEveryLinkEndedSkipsOwnPredecessorsAndATodosMemoryLinks in `source/hooks/internal/memory/ends_test.go`:

1. A todo linking only to a retired memory entry is no candidate.
2. A trap linking its retired fix todo is a candidate.
3. An entry linking a memory target it superseded does not count that link as ended (rows for a todo and a note).
4. A todo with a closed graph link is a candidate, also beside a live or a retired memory link.

`docs/memory/usage.md` and `docs/memory/architecture.md` change in the same commit; the skill needed no change of its own, as the directive set.

Live on the installed binary: in the brief, todos linking only to a retired memory entry show `→ 1 ended` without a `retire?` flag, and the only `retire?` candidate left is a note.
