Only using an agentic-memory entry warms it now, and `who` counts each seat's filed and used entries, in agentic-helpers commits db6e9bb and 417fc11, not yet released, completing 20261026-222129-d-tac-ak9.

Each criterion with its test in `internal/memory/heat_test.go`:

1. Recall leaves `heat.json` unchanged: TestRecallWarmsNothing.
2. `link` warms a memory target and `ack --done` the rule, by 0.5 each, `--no-heat` lifting both, CLI and MCP: TestALinkWarmsItsMemoryTarget, TestADoneAckWarmsTheRule.
3. `who` prints `filed <n> / used <m> (14d)` per seat: TestWhoCountsFiledAndUsedEntriesPerSeat, over a store the harness builds with a fake clock rather than a fixture store, since the harness mints the entry ids. `who --json` carries `filed` and `used` (`jsonreads_test.go`), checked for the keys, not their values.
4. The docs and agentic-helpers:agent-memory name every heat event and amount, `--no-heat` on `ack`, and the counts.

Deviation fixed in 417fc11: `ack --decline` warmed the rule too, though a decline answers a rule without acting on it; only `ack --done` warms.
