agentic-helpers v3.0.0 removes the `json` key from every schema of the plugin's `memory` and `tools` MCP servers. Since 20261027-180531-d-tac-04v every MCP answer is JSON and the key has no effect; once it is unlisted, a call still passing it is refused as an unknown key (20261025-034140-d-tac-9os). The CLI's `--json` flags stay: on the command line text is still the default and `--json` still selects the JSON form.

Why: a key that does nothing reads as an option to callers and to anyone reading a schema, and the removal is a breaking change for callers that pass it, so it waits for the next major release rather than landing in a minor one.

Rejected: removing it in the release that makes answers JSON, which refuses callers passing it without a major release; keeping it for good, which leaves a dead key in every schema that lists it.

Accepted costs: a caller passing `json` after v3.0.0 is refused once and retries without it; the change ships as `feat!:` or with a `BREAKING CHANGE` so the release is a major one.

Done when no MCP schema lists `json`, a call passing it is refused naming the key, the CLI `--json` flags answer as before, and the skills and docs name no MCP `json` key.
