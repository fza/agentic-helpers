Done for 20261025-152555-d-tac-86k: commit f0fef30, with the claim's `started` in 7441d6f, released as v2.3.0 (release commit e355cfc).

- Tail rows write `time` as RFC 3339 UTC with every nanosecond and read Unix nanoseconds beside it; memory's clock runs in UTC, so `claimed`, heat, brief marks and ladders are written in UTC; `register.ts` writes `at` as `toISOString()`, and memory reads a numeric `at` as Unix seconds too. Binary segments keep their nanoseconds.
- Tests: `TestATailRowCarriesItsTimeAsRFC3339`, `TestATailReadsTimesInEitherForm` (fixture `memorylog/tail-mixed-times.jsonl`), `TestStoredTimesAreUTC` under a CET clock, `TestAContextReadingIsReadInEitherForm`, and `claude plugin test plugin`; each guard was broken and caught.
- The tail rows earlier releases wrote are rewritten by the format-2 migration of 20261025-155655-d-tac-jyw.
- AC 3 shipped ahead in 7441d6f (20261025-162618-d-tac-hsx): `process.StartTime` runs `ps -o lstart=` under `LC_ALL=C` and returns a `time.Time`; `TestParseLstart` parses fixture `lstart` lines in a fixed zone (`Europe/Berlin`), and `TestStartTimeAsksPsInTheCLocale` drives a fake `ps` answering in German unless `LC_ALL=C` is set.
- Docs: the stored format is named in `docs/memory/architecture.md`, "Times"; the README carries no internals since dfd13bd, so `docs/` stands in for it.
