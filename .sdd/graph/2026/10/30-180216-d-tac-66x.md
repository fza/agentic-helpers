Every agentic-helpers option with a fixed value set is declared in `userConfig` as a picker, with `options` and a `default` equal to the option reader's built-in default: `embedding_provider` (`auto`), `writing_style` (`terse`), `scratch_sweep` (`release`), `shell_guard_outside_project` (`ask`), `shell_guard_find_delete` (`ask`), `shell_guard_secrets` (`ask`) and `shell_guard_secret_output` (`all`). Claude Code refuses a picker that declares neither a `default` nor `required: true`.

This supersedes 20261030-113044-d-tac-is5, whose rule it keeps except on one point: is5 kept `embedding_provider` a text field, because its unset state had no value a picker could offer. 20261030-175918-d-tac-iwd gives that state a value, `auto`, which takes the embedding configuration the `sdd` tool sets, exactly as an unset provider did, and folds `embedding_source` into the provider; `embedding_source` is therefore no longer declared and drops out of this list, while the reader keeps reading it.

**Why a declared default is safe.** A probe on Claude Code 2.1.314 found that a hook receives no `CLAUDE_PLUGIN_OPTION_*` variable for a picker nobody answered, so its declared default never reaches a hook and `config.yaml` keeps deciding. A dialog saved untouched does store each picker's default, and 20261030-120442-d-tac-iuc has the reader treat an agent-layer answer equal to the built-in value as unset, so that save hides `config.yaml` neither. The exception to the no-declared-defaults rule covers pickers and, by 20261030-120442-d-tac-iuc, booleans; text and number options still declare none.

**Minimum Claude Code.** `options` needs v2.1.271, as 20261030-083534-d-tac-ws7 accepted; README states it. ws7's bounds half stands as built.

**Rejected.**
- `required: true`: forces every install to answer, and the answers hide `config.yaml`.
- Dropping pickers: a typo in a dialog answer stays possible and surfaces only as an error at the next hook.
- Keeping `embedding_provider` a text field, as is5 did: the provider was the one fixed-choice option a typo could still reach, and its unset state now has a name.

**Accepted costs.** Each picker's values and default are a second copy of what the reader validates, kept in step by `internal/plugin/options_test.go`.

**Acceptance.**
1. The seven pickers declare `options` and the reader's built-in default; `embedding_source` is not declared; `claude plugin validate .` passes.
2. The options test checks that each picker's values are all the reader accepts, a value outside them is refused, and each declared default equals the built-in one.
3. README names Claude Code v2.1.271 as the minimum, and `docs/plugin/usage.md` states the picker exception and lists `embedding_provider` among the pickers.
