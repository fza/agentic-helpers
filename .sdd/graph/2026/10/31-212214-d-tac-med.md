title: Judging `mv` and `git mv` sources like removals
summary: Shell-guard will judge each source operand of `mv` and `git mv` with the removal verdict that path would get, closing the two-step removal of files outside the project. The target operand and `cp` sources stay unjudged, since moving into the project or copying removes nothing. Moving a file in from outside now costs the confirmation a removal there needs, and docs plus the agent-shell-guard skill will name `mv` among what is judged.
---

Shell-guard judges each source of `mv` and `git mv` as it judges the operand of a removal: a source outside the project and `/tmp` gets the verdict `rm` of that path would get. A move takes a file away from where it was, so today `mv ~/important /tmp/x` followed by `rm /tmp/x` removes anything outside the project in two steps that each pass, and `mv ~/x ./` alone empties a place shell-guard is meant to protect.

**What is judged.** Every operand of `mv` but the last (the target), and of `git mv` likewise, with the same path reading removals use: a path built from a variable or substitution gets the verdict an unreadable removal operand gets, a glob is judged as a pattern. Options are skipped by their value tables (`-t <dir>` names the target, so every other operand is a source).

**Not judged.** The target: moving into the project or `/tmp` removes nothing there. `cp`: it reads its source and removes nothing, and shell-guard does not guard reads.

**Rejected.** Judging `cp` sources too: it would ask on copying a file in from outside, a common and harmless read, guarding reading where shell-guard otherwise does not. Leaving `mv` unjudged: the two-step removal stays open.

**Accepted cost.** Moving a file from outside, such as a download from `~/Downloads` into the project, needs the confirmation a removal there needs.

**Acceptance.**
- `mv <outside>/x ./` and `git mv` from outside get the removal verdict; `mv ./a ./b` and `mv ./build /tmp/old` pass.
- `mv -t ./dir <outside>/x` judges `<outside>/x` as the source.
- `cp <outside>/x ./` passes.
- `docs/shell-guard/` and the agent-shell-guard skill name `mv` among what is judged.
