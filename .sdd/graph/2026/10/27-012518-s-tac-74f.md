Each criterion with its test:

1. Every gitleaks sample, `positive/`, `negative/` and `clean.txt`, each mechanism's break failing it: TestScanFixtures, TestScanGitleaksSamples, TestScanCleanTextFindsNothing.
2. No keyword, no pattern compiled: TestScanCompilesNoPatternForTextWithoutKeywords.
3. memory `new`, `state` and `attach` (CLI and MCP), tools `add` and `update` (CLI and MCP) refuse with the stated wording; neither prompt hook embeds a prompt holding one, recall answers by terms, the notice prints once: `memory/credentials_test.go`, TestAttachingACredentialLaterIsRefused, TestWritesRefuseACredential, TestTheMCPAddRefusesACredential, TestTheMCPUpdateRefusesACredential, TestAPromptHoldingACredentialIsRecalledByTermsWithoutAnEmbed, TestThePromptOfferNeverEmbedsAPromptHoldingACredential.
4. shell-guard asks, denies or stays silent per `shell_guard_secrets`: TestACommandHoldingACredentialIsJudgedByItsOption.
5. The gate denies `sdd new`, a draft and an `mcp__sdd__next` report: TestAGraphWriteHoldingACredentialIsRefused.
6. The migration scan tells the owning seat once: TestTheMigrationScanTellsTheOwningSeatOnce.
7. `rules.json` carries the pin and license, matches the fork at `26f1aaec`: TestVendoredRulesMatchThePin; `vendor-rules.py` reproduces it byte for byte, checked by hand, since no test fetches upstream.
8. Entropy, allowlist targets and conditions, `gitleaks:allow`: TestScanSemantics, TestScanIgnoresTheGitleaksAllowMarker.
9. `docs/secrets/` and every skill quoting a refusal.

Deviations: the gate decodes an engine report and scans each value, since JSON escapes hid five of the thirteen positive samples when read as opaque text. Beyond the directive: the gate also scans `mcp__sdd__start_procedure` params and `mcp__sdd__stage_attachment` content, refuses an attachment it cannot read or place (stdin, a shell expansion, a relative path after a directory change or behind a launcher), scans attachments past path allowlists, and agentic-capture rescans the exact bytes it hands sdd. Its limits, an evading agent rather than an accidental paste, are written in `docs/secrets/architecture.md`.
