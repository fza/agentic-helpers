agentic-memory's Stop and SessionEnd hooks now write a marked draft of a seat's state slot wherever no state the agent wrote is newer than the seat's claim, closing 20261027-222635-d-tac-fki. Commit 6b4514f, not yet released.

- The draft lists the commits since the claim (`git log --oneline -n 20 <claim commit>..HEAD`, from a new claim field `commit`), the files the session's Edit, Write and NotebookEdit calls named (each once, the first 20, relative to the work tree), and the last prompt, cut to `entry_max_words`. A prompt the credential scan withholds never reaches it.
- The `state` row carries `draft: true`; the brief opens it `state (<age> old, branch <b>, hook draft): <body>` and `brief --json` carries `draft`. Writing it prints nothing, and an unchanged draft is not written again.
- The fold never lets a draft replace a non-draft state of the same session, and a log merge keeps the state row the fold reads rather than the newest. A draft answers no compaction nudge, re-arms no replay nudge, and clears no shipped-work hold.
- Tests in `internal/memory/draft_test.go` and `internal/memory/draft_internal_test.go` cover each acceptance criterion, the racing write through the fold and the merge, the word limit and the withheld prompt. Every guard was broken and its test watched failing, files restored byte-identically. The check skipping a draft where the agent's state is newer than the claim is masked by the fold rule for what the brief shows; a test that a Stop after the agent's state writes no log row catches it alone, and breaking both together fails the fold tests.
- Proven on binaries built from the commit, against a throwaway home and repository: after a prompt, a file write and a real commit, Stop printed nothing and the brief opened on the marked draft listing all three, with `draft` true in JSON; the agent's state write replaced it and survived a later Stop and SessionEnd; a session ending without any state left a draft its next claim showed.
- `docs/memory/usage.md`, `docs/memory/architecture.md` and agentic-helpers:agent-memory describe drafts.
