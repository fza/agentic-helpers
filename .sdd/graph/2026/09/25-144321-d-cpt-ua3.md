The agent helpers keep one source, this repository, and reach each project from here rather than as copies inside it, because copies drift and every change had to be repeated in each project carrying one.

The hooks and skills described in 20260925-144221-s-cpt-yz3 reach a project two ways: `install.py` adds hook entries to the global Claude Code settings file (`~/.claude/settings.json`) that run the scripts in this checkout, and symlinks each skill directory into the global skills directory, so every project on the machine sees the same files. An edit here reaches every project at once, and a project takes part by carrying the directory a hook works on rather than by vendoring the helper.

Rejected: per-project copies, for the drift and repeated edits they caused when the helpers lived that way. Accepted cost: every machine needs this checkout and a run of `install.py` before a project benefits, and a change here lands in every project simultaneously, so a broken hook breaks everywhere at once.

Violation is observable: a hook script or skill body committed inside another project's tree instead of wired or linked from here.
