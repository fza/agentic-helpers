The grounding gate removes its own session ledgers. `agentic-grounding-gate end`, wired by `agentic-install` as a `SessionEnd` entry, deletes `.sdd/tmp/grounding-gate/<session>.json` and every `<session>.<agent>.json` beside it. `agentic-grounding-gate start`, wired as a `SessionStart` entry, deletes any file in that directory whose name is a session id, optionally followed by `.<agent>`, then `.json`, and which was last modified more than 7 days ago. A file with any other name is kept whatever its age. Both modes stay silent and exit 0 in a project without `.sdd/`, and a failed removal is ignored.

Why: a ledger is written for every session and nothing deleted it, so `.sdd/tmp/grounding-gate/` grew by one file per session for good. The ledger carries a `grounded` list that lives as long as the session, which gives it a clear end: the session's own end. `SessionEnd` does not fire for a session that crashed or was killed, so a later start reaps what that left. The pattern, 7 days and the rule that only session-shaped names are ever removed, is the one `agentic-scratch` already runs for `.tmp/claude/<session-id>/`.

Rejected: reaping by age alone inside the `turn` mode. It adds a directory scan to every prompt and keeps each ledger up to a week past its session. Rejected: extending `agentic-scratch` to sweep `.sdd/tmp/grounding-gate/`. One hook would delete another hook's state, and `agentic-scratch` stays silent in a project without `.tmp/`, so the ledgers of such a project would still never go.

Accepted cost: two new modes and two new hook entries, so `agentic-install` rewrites `~/.claude/settings.json`. A session resumed after `SessionEnd` fired starts with no ledger, so its drafts are no longer grounded and its next capture owes the three reads. The capture lock `.sdd/tmp/capture.lock` and files an agent writes by hand under `.sdd/tmp/` are out of scope and stay. `README.md` and `skills/agent-grounding` describe both modes in the same change.

Acceptance:

- A functional test runs `end` for a session and finds its ledger and its agent ledgers gone and another session's ledger kept.
- A functional test runs `start` and finds a session-named ledger older than 7 days removed, a younger one kept, and an old file with a non-session name kept.
- Both modes exit 0 and create nothing in a project without `.sdd/`.
- `agentic-install --print` shows the `SessionEnd` and `SessionStart` entries for `agentic-grounding-gate`.
- Each new guard is broken, its test watched failing, and the file restored byte-identically.
