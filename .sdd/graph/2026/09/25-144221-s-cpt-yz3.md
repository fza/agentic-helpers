agentic-helpers is a set of machine-wide Claude Code hooks, each paired with a skill that explains it to the agent, that a project opts into by carrying the directory the hook works on.

Three hooks: the carry-forward keeps a per-seat handover file under `.memory/` so the next session picks up the work; the scratch sweep removes each session's throwaway directory under `.tmp/`; the grounding gate refuses questions and drafts against an sdd graph under `.sdd/` until the same turn has run a literal search, a semantic search and an area listing. The hooks install once from this checkout (`install.py` wires them into the global Claude Code settings and links the skills) and reach every project on the machine; a project without the matching directory is left alone, the hook exiting silently and creating nothing. The hooks are plain Python with no dependencies. The README carries install steps and the full behaviour of each hook.
