The hooks bind to no sdd-autopilot state. The carry-forward registers no seat with `sddap` and reads or clears no `<role>.autopilot` budget file. The grounding gate keeps its ledger in `.sdd/tmp/grounding-gate/`, which sdd already ignores, rather than in `.sdd/autopilot/turns/` or wherever `GRAPH_LEDGER_DIR` points, and it no longer exempts a draft edit because an sdd-autopilot verification recorded reading that draft.

Why: sdd-autopilot is a separate tool with its own seat registry, budgets and verification records, and nothing in these hooks is part of it. A hook reaching into another tool's files breaks whenever that tool changes its layout, and runs code for a tool a project may not use at all.

Rejected: keeping the calls as optional, silent when the tool is absent. The hooks would still encode another tool's file layout and command surface.

Accepted cost: a draft edit answering a verification's findings now owes the turn's reads like any other draft edit.

Settled: agentic-helpers commit 1274b11 removes every binding, with the suites passing; nothing further is owed.
